# اصلاحات CRM، تاریخ شمسی و مراحل سفارش — 2026-08-07

این نسخه بعد از بررسی ایرادهای جدید آماده شد.

## اصلاحات انجام‌شده

1. اسکرول لیست مشتریان CRM
   - لیست مشتریان دیگر با زیاد شدن تعداد مشتری کل صفحه را بی‌نهایت پایین نمی‌کشد.
   - جدول مشتریان ارتفاع محدود دارد و خودش اسکرول می‌خورد.
   - Header جدول ثابت می‌ماند.

2. انتقال پرونده مشتری
   - کارت/لیستی که در عکس فرستادی با عنوان `Customer File` دقیقاً به زیر بخش لیست مشتریان منتقل شد.
   - دیگر بعد از قیف فروش و تعاملات نمی‌آید.

3. نوار مراحل سفارش شبیه HTML
   - در تب مراحل سفارش، کارت هر سفارش حالا Stepper خطی دارد.
   - دایره‌های مرحله، خط اتصال، مرحله انجام‌شده و مرحله فعلی مثل فایل HTML طراحی شد.
   - با زیاد شدن مراحل، خود Stepper اسکرول افقی می‌خورد و صفحه خراب نمی‌شود.

4. تاریخ شمسی واقعی در ورودی‌ها
   - ورودی‌های `type=date` میلادی حذف شد.
   - کامپوننت جدید `JalaliDateInput` اضافه شد.
   - کاربر تاریخ را به صورت شمسی وارد می‌کند؛ مثال:
     `۱۴۰۵/۰۵/۱۷`
   - سیستم پشت صحنه تاریخ را به فرمت استاندارد دیتابیس تبدیل می‌کند.

5. جاهایی که ورودی تاریخ شمسی شد
   - سفارش جدید: تاریخ ثبت و موعد تحویل
   - پیگیری CRM: تاریخ پیگیری
   - مشتری/سرنخ CRM: پیگیری بعدی
   - ارجاعات مشترک: موعد ارجاع
   - مالی: تاریخ صدور، سررسید، تاریخ پرداخت، سررسید چک، موعد ارجاع
   - داشبورد: فیلتر از تاریخ / تا تاریخ
   - R&D: تاریخ موعد فرم
