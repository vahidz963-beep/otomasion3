# نسخه کامل نهایی پروژه تا این مرحله

تاریخ آماده‌سازی: 2026-08-09

این ZIP نسخه کامل سورس پروژه اتوماسیون است و شامل تمام تغییرات انجام‌شده تا این مرحله است.

## شامل ماژول‌ها و اصلاحات

### سفارش‌ها و CRM
- اصلاح CRM مشتریان
- اصلاح هدر آبی سفارش‌ها
- مراحل سفارش با Drawer سمت چپ
- قالب‌های قابل تنظیم سفارش
- خروجی‌های برنددار

### انبار
- اصلاح سند موقت ورود و خروج
- سند موقت جدا برای ورود و خروج
- اصلاح خطای حذف/انصراف سند موقت
- نام مشتری و شرح کلی سند
- کاردکس به عنوان بخش اصلی
- همگام‌سازی انبارا با کالاهای هماهنگ‌شده، مچ‌نشده و غیرفعال
- گزارش‌های انبار با خروجی Excel/Word
- ثبت موجودی اولیه/اصلاحی در سند موقت

### تولید
- ماژول تولید واقعی React
- تأیید سفارش‌های رسیده از سفارش‌ها
- مراحل تولید با ظاهر مشابه سفارش‌ها
- برنامه‌ریزی تولید
- فرمول تولید کالا و هزینه‌ها
- کنترل کیفیت
- اسناد تولید
- ارجاعات تولید
- تنظیم قالب‌های تولید ۴ تا ۱۵ مرحله

### R&D
- ماژول R&D واقعی React
- دریافت پروژه از سفارش یا پروژه داخلی
- مراحل R&D با ظاهر مشابه سفارش‌ها
- هزینه‌ها شامل نفرساعت، متریال، خدمات، تست و سربار
- تست‌ها با جزئیات کامل
- پروژه‌ها با جزئیات و Drawer
- تنظیم قالب‌های R&D از ۴ تا ۱۵ مرحله
- فایل‌های اشتراکی در ارجاعات

### فایل‌های اشتراکی
- بخش Shared Files برای ارجاعات همه ماژول‌ها
- ارسال فایل
- دانلود فایل
- مشاهده فایل‌های اشتراک‌گذاشته‌شده بین سفارش، تولید، R&D، مالی، اداری و انبار

## SQLهای جدیدی که باید در Supabase اجرا شوند

اگر قبلاً اجرا نکرده‌ای، به ترتیب اجرا کن:

1. `supabase/migrations/019_warehouse_in_out_draft_documents.sql`
2. `supabase/migrations/020_warehouse_cancel_fk_meta_and_summary.sql`
3. `supabase/migrations/021_production_module_backend_workflow.sql`
4. `supabase/migrations/022_rnd_module_workflow_and_shared_files.sql`

خیلی مهم: اگر هر SQL خطا داد، ادامه نده و عکس/متن خطا را بفرست.

## روش آپلود در GitHub/Netlify

1. ZIP را Extract کن.
2. وارد پوشه Extract شده شو.
3. همه فایل‌ها و پوشه‌های داخل آن را Copy کن.
4. داخل پروژه اصلی `otomasion3` یا ریپوی متصل به Netlify جدید Paste کن.
5. Replace / Overwrite را تأیید کن.
6. GitHub Desktop را باز کن.
7. Summary بنویس:
   `full project with production rnd warehouse final updates`
8. Commit to main بزن.
9. Push origin بزن.
10. SQLهای بالا را در Supabase اجرا کن.
11. Netlify Deploy بگیر.
12. آدرس جدید فعلی:
   `https://automationarya.netlify.app/?v=full-rnd-production-warehouse-final`
