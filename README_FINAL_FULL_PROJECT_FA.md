# نسخه کامل نهایی پروژه اتوماسیون — V5

تاریخ آماده‌سازی: 2026-08-09

این ZIP نسخه کامل سورس پروژه اتوماسیون است و شامل اصلاحات پایدارسازی بعد از خطاهای تولید، R&D، انبار، ارجاع و فایل‌های اشتراکی است.

## اصلاحات مهم این نسخه

### پایدارسازی کلی
- یک Error Boundary به برنامه اضافه شد تا اگر یک ماژول خطای نمایشی داد، کل سایت سفید نشود و فقط همان ماژول پیام خطا نشان دهد.

### تولید
- ماژول تولید واقعی React فعال است.
- سفارش پس از تأیید به برنامه‌ریزی تولید منتقل می‌شود.
- فرمول تولید کالا هزینه نهایی را به قیمت کالا در انبار تبدیل می‌کند.
- کالاهای تولیدی با دسته `Finished` در انبار ثبت/به‌روزرسانی می‌شوند.
- قیمت نهایی کالا برای انبار، سفارش و مالی قابل مشاهده است.
- ارجاع هزینه تولید به مالی ثبت می‌شود.
- مشکل `order_events.created_by` با SQL 024 رفع می‌شود.

### R&D
- ماژول R&D واقعی React فعال است.
- دریافت پروژه از سفارش یا پروژه داخلی وجود دارد.
- مراحل R&D مثل سفارش‌ها نمایش داده می‌شود.
- هزینه‌ها، نفرساعت، متریال و تست قابل ثبت است.
- بخش «نسخه‌ها و فایل‌ها» قدیمی حذف شد و فایل‌های اشتراکی به «ارجاع و اسناد» منتقل شد.
- خطای موجودی `available_for_sale_qty` با اصلاح Hook و SQL 024 رفع می‌شود.

### ارجاع و اسناد / فایل‌های اشتراکی
- عنوان بخش ارجاع به «ارجاع و اسناد» تغییر کرد.
- ارجاعات و فایل‌های اشتراکی به صورت دو کارت جدا و تمام‌عرض زیر هم نمایش داده می‌شوند.
- فایل‌های اشتراکی فولدر مجزا برای هر ماژول دارند:
  - orders
  - production
  - rnd
  - warehouse
  - accounting
  - admin
  - office
  - manual
- فایل‌ها در Supabase Storage و bucket زیر ذخیره می‌شوند:
  `automation-shared-files`
- در دیتابیس فقط متادیتا و مسیر فایل ذخیره می‌شود.

### انبار
- خطای سفید شدن صفحه موجودی به علت `formatNumber` رفع شد.
- خطای `customer_city` در view اسناد با سازگاری فرانت رفع شد.
- سند موقت ورود و خروج، حذف امن سند، کاردکس، گزارش‌ها و همگام‌سازی طبق نسخه‌های قبلی حفظ شدند.

5. Summary بنویس:
   `full final v5 stable automation project`
6. Commit to main بزن.
7. Push origin بزن.
8. SQLهای بالا را در Supabase اجرا کن.
