# نسخه کامل نهایی پروژه اتوماسیون

تاریخ آماده‌سازی: 2026-08-09

این ZIP نسخه کامل سورس پروژه اتوماسیون است و شامل همه تغییرات انجام‌شده تا این مرحله است.

## تغییرات مهم این نسخه

### سفارش‌ها و CRM
- اصلاح CRM مشتریان
- اصلاح هدر آبی سفارش‌ها
- مراحل سفارش با Drawer سمت چپ
- قالب‌های قابل تنظیم سفارش
- خروجی‌های برنددار

### انبار
- سند موقت ورود و خروج جداگانه
- حذف/لغو سند نهایی با برگشت اثر موجودی به انبار
- سؤال حذف سند در Modal شیک و هماهنگ با اتوماسیون
- حذف promptهای مرورگر از ویرایش ردیف و انبارگردانی
- ویرایش ردیف سند در Modal تمیز
- هشدار موجودی منفی هنگام خروج کالا
- نام مشتری، شهر و شرح کلی برای سند
- ذخیره خودکار اطلاعات سند بدون دکمه ذخیره
- کاردکس به عنوان تب اصلی با جست‌وجو و انتخاب کالا
- مرتب‌سازی ستون‌ها در موجودی و اسناد
- برگشت کالاهای غیرفعال/حذف‌شده از بخش همگام‌سازی
- گزارش‌ها با پیش‌نمایش و خروجی Excel / PDF / Word

### تولید
- ماژول تولید واقعی React
- تأیید سفارش‌های رسیده از سفارش‌ها
- انتقال سفارش تأییدشده به برنامه‌ریزی تولید
- مراحل تولید با ظاهر مشابه سفارش‌ها
- برنامه‌ریزی تولید
- فرمول تولید کالا و هزینه‌ها
- ثبت قیمت نهایی فرمول تولید در کالای انبار
- کالای تولیدشده با قیمت نهایی در انبار، سفارش‌ها و مالی قابل مشاهده است
- ارجاع هزینه تولید به مالی
- کنترل کیفیت
- اسناد تولید
- تنظیم قالب‌های تولید ۴ تا ۱۵ مرحله

### R&D
- ماژول R&D واقعی React
- دریافت پروژه از سفارش یا پروژه داخلی
- مراحل R&D با ظاهر مشابه سفارش‌ها
- هزینه‌ها شامل نفرساعت، متریال، خدمات، تست و سربار
- تست‌ها با جزئیات کامل
- پروژه‌ها با جزئیات و Drawer
- تنظیم قالب‌های R&D از ۴ تا ۱۵ مرحله
- حذف بخش نسخه‌ها و فایل‌ها از ساختار قدیمی

### ارجاع و اسناد / فایل‌های اشتراکی
- نام بخش ارجاع به «ارجاع و اسناد» تغییر کرد
- در بخش ارجاع و اسناد، کارت ارجاعات و کارت فایل‌های اشتراکی جدا هستند
- فایل‌های اشتراکی بین همه ماژول‌ها قابل مشاهده و دانلود هستند
- هر ماژول فولدر خودش را دارد: orders، production، rnd، warehouse، accounting، admin و ...
- فایل‌ها در Supabase Storage و bucket زیر ذخیره می‌شوند:
  `automation-shared-files`
- در دیتابیس فقط متادیتا و مسیر Storage ذخیره می‌شود، نه خود فایل Base64

## روش آپلود در GitHub/Netlify

1. ZIP را Extract کن.
2. وارد پوشه Extract شده شو.
3. همه فایل‌ها و پوشه‌های داخل آن را Copy کن.
4. داخل پروژه اصلی یا ریپوی متصل به Netlify جدید Paste کن.
5. Replace / Overwrite را تأیید کن.
6. GitHub Desktop را باز کن.
7. Summary بنویس:
   `full final automation project production rnd warehouse storage`
8. Commit to main بزن.
9. Push origin بزن.
10. SQLهای بالا را در Supabase اجرا کن.
11. Netlify Deploy بگیر.
12. آدرس تست:
   `https://automationarya.netlify.app/?v=full-final-storage-production-rnd`
