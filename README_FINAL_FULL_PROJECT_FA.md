# نسخه کامل نهایی پروژه اتوماسیون — V6

تاریخ آماده‌سازی: 2026-08-09

این ZIP نسخه کامل سورس پروژه است و شامل اصلاحات پایدارسازی R&D، تولید، انبار، ارجاع و اسناد، فایل‌های اشتراکی، نقش‌های کاربری و اضافه شدن ماژول امور اداری است.

## اصلاحات مهم این نسخه

### 1. رفع خطای R&D
- خطای `SharedFilesPanel is not defined` رفع شد.
- فایل‌های اشتراکی در R&D دوباره درست import و نمایش داده می‌شوند.

### 2. ارجاع و اسناد
- ارجاعات و فایل‌های اشتراکی به صورت دو کارت جدا و تمام‌عرض زیر هم نمایش داده می‌شوند.
- پاسخ به ارجاع دیگر با prompt مرورگر نیست و در Modal هماهنگ با اتوماسیون انجام می‌شود.
- جزئیات، شرح و پاسخ ارجاع قابل مشاهده است.

### 3. فایل‌های اشتراکی
- فایل‌ها در Supabase Storage ذخیره می‌شوند.
- فولدر جدا برای هر بخش وجود دارد:
  - orders
  - production
  - rnd
  - warehouse
  - accounting
  - admin
  - office
  - manual
- دکمه حذف فایل اضافه شد.
- هر بخش می‌تواند فایل‌های خودش را حذف کند.
- مدیر کل می‌تواند همه فایل‌ها را حذف کند.
- حذف فایل هم از Storage و هم از جدول متادیتا انجام می‌شود.

### 4. کاربران و نقش‌ها
- پشتیبانی اولیه از چند نقش برای هر کاربر اضافه شد.
- هر کاربر می‌تواند تا ۳ نقش داشته باشد.
- نقش `مدیر فروش` اضافه شد.
- در منوی اصلی، ماژول سفارش‌ها فقط برای مدیر کل، فروش و مدیر فروش نمایش داده می‌شود.

### 5. امور اداری
- ماژول امور اداری اضافه شد.
- شامل بخش‌های:
  - نمای کلی
  - کارتابل
  - دبیرخانه/نامه‌ها
  - بایگانی اسناد
  - جلسات
  - مرخصی و حضور
  - ارجاع و اسناد
  - تنظیمات

### 6. تولید
- کالاهای تولیدی از فرمول تولید به انبار منتقل می‌شوند و قیمت نهایی آن‌ها در انبار ثبت می‌شود.
- هزینه تولید به مالی ارجاع می‌شود.
- بعد از تأیید سفارش، کاربر به برنامه‌ریزی تولید منتقل می‌شود.

### 7. انبار
- اصلاحات قبلی انبار حفظ شده است.
- حذف سند، برگشت موجودی، گزارش‌ها، کاردکس و اسناد موقت در نسخه کامل موجود هستند.

## روش نصب

1. ZIP را Extract کن.
2. همه فایل‌ها را داخل پروژه اصلی یا ریپوی متصل به Netlify کپی کن.
3. Replace / Overwrite را تأیید کن.
4. GitHub Desktop را باز کن.
5. Summary بنویس:
   `full final v6 office shared files roles stable`
6. Commit to main بزن.
7. Push origin بزن.
8. SQLهای بالا را در Supabase اجرا کن.
9. Netlify Deploy بگیر.
10. تست:
   `https://automationarya.netlify.app/?v=full-final-v6`
