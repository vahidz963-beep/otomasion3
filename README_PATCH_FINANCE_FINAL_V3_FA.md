# پچ اصلاح واقعی مالی/حسابداری V3

تاریخ آماده‌سازی: 2026-08-14

این پچ برای رفع مواردی است که در نسخه قبلی کامل در UI دیده نشده بود.

## موارد اصلاح‌شده

1. فاکتورها:
   - فاکتورهای ثبت‌شده تمام‌عرض شدند.
   - پیش‌فاکتورها تمام‌عرض شدند.
   - جزئیات سند تمام‌عرض شد.
   - پیش‌فاکتور تبدیل‌شده از لیست پیش‌فاکتورها خارج می‌شود.
   - سند باطل‌شده از لیست فعال حذف می‌شود.
   - وضعیت پیش‌نویس در فاکتورهای ثبت‌شده حذف شد؛ اسناد جدید به صورت تأیید/ثبت‌شده ایجاد می‌شوند.
   - مرتب‌سازی ستون‌ها اضافه شد.

2. دریافت/پرداخت:
   - گزینه بدون شخص حفظ شد.
   - فاکتور مرتبط بر اساس شخص انتخاب‌شده فیلتر می‌شود.
   - واریزی‌ها سبز و برداشت‌ها قرمز شدند.
   - گردش حساب با همه واریزها و برداشت‌ها نمایش داده می‌شود.
   - ستون‌های گردش حساب sortable شدند.

3. اشخاص و صورت‌حساب:
   - صورت‌حساب شخص شامل فاکتور، واریز و برداشت است.
   - لیست بدهکار/بستانکار اشخاص با مانده صفر را حذف می‌کند.
   - مرتب‌سازی ستون‌ها اضافه شد.
   - ثبت شخص جدید اضافه شد و با مشتریان هماهنگ می‌شود.

4. صندوق و گردش حساب:
   - حساب‌ها و صندوق‌ها با موجودی فعلی نمایش داده می‌شوند.
   - گردش بانک و صندوق نمایش و فیلتر می‌شود.
   - سرمایه‌گذاری‌ها قابل ثبت/ویرایش/آرشیو شدند.

5. چک‌ها:
   - بخش چک‌ها جدا و حرفه‌ای‌تر شد.
   - ثبت چک جدید، فیلتر، تغییر وضعیت و وصول/تسویه به حساب بانکی اضافه شد.

6. کاردکس کالاها:
   - همه کالاها پایین لیست می‌شوند.
   - گروه کالا قابل انتخاب است.
   - قیمت مرجع و آخرین قیمت فروش نمایش داده می‌شود.
   - کالاهای تولیدی با عنوان «تولید شده‌ها» دیده می‌شوند.
   - کاردکس فقط نمایشی است.

7. نمای کلی مالی:
   - ارجاعات باز زمینه سفید دارد.
   - آخرین فاکتورها تمام‌عرض شدند.
   - آخرین گردش حساب تمام‌عرض شد.
   - چک‌ها تمام‌عرض شدند.
   - KPIها قابل کلیک هستند.

8. هدر آبی مالی:
   - فاکتور از سفارش
   - فاکتور جدید
   - دریافت/پرداخت
   - به‌روزرسانی

9. شماره‌گذاری شمسی:
   - SQL شماره 030 شماره‌های جدید را با سال 1405 می‌سازد.
