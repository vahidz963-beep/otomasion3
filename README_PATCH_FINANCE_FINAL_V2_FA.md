# پچ پایدارسازی نهایی مالی + اصلاح شماره‌گذاری شمسی

تاریخ آماده‌سازی: 2026-08-14

## اصلاحات مالی

### 1. ترتیب تب‌ها
ترتیب تب‌های مالی مطابق درخواست شد:
1. نمای کلی
2. فاکتورها
3. اشخاص و صورت‌حساب‌ها
4. صندوق و گردش حساب
5. چک‌ها
6. کاردکس کالاها
7. سود سفارش‌ها
8. دوره مالی
9. ارجاعات
10. تنظیمات

### 2. هدر آبی مالی
فقط سه گزینه اصلی باقی ماند:
- فاکتور از سفارش — طلایی
- فاکتور جدید
- دریافت/پرداخت

### 3. فاکتورها
- فاکتورهای ثبت‌شده تمام‌عرض شدند.
- پیش‌فاکتورها تمام‌عرض شدند.
- جزئیات سند تمام‌عرض شد.
- پیش‌فاکتور پس از تبدیل از لیست پیش‌فاکتورها خارج می‌شود.
- سند ابطال‌شده از لیست فعال حذف می‌شود.
- ابطال و برگشتی با Modal تمیز انجام می‌شود، نه prompt مرورگر.
- ستون‌های فاکتورها sortable شدند.

### 4. صورت‌حساب اشخاص
- صورت‌حساب هر شخص شامل فاکتورها، واریزی‌ها و برداشت‌های همان شخص است.
- لیست بدهکار/بستانکار صفرها را نمایش نمی‌دهد.
- جدول بدهکار/بستانکار sortable شد.

### 5. دریافت و پرداخت
- گزینه «بدون شخص» حفظ شد تا تنخواه و موارد عمومی ثبت شوند.
- فاکتور مرتبط براساس شخص انتخاب‌شده فیلتر می‌شود.
- واریزی‌ها سبز و برداشت‌ها قرمز ملایم نمایش داده می‌شوند.
- گردش حساب sortable شد.

### 6. صندوق و گردش حساب
- نمایش حساب‌های بانکی و صندوق‌ها
- موجودی فعلی هر حساب
- جمع واریز و برداشت
- گردش حساب با فیلتر حساب، نوع گردش و جست‌وجو

### 7. سرمایه‌گذاری
- ثبت سرمایه‌گذاری اصلاح شد.
- انواع دارایی مثل طلا، نقره، زمین، ارز، تجهیزات و... قابل ثبت است.
- ویرایش و آرشیو سرمایه‌گذاری اضافه شد.

### 8. چک‌ها
- بخش چک‌ها جدا شد.
- ثبت چک جدید
- فیلتر نوع و وضعیت
- وصول/تسویه چک به بانک
- با پاس شدن چک، گردش بانکی ثبت می‌شود.

### 9. کاردکس کالاها
- همه کالاها قابل جست‌وجو و انتخاب هستند.
- ورود، خروج و مانده کالا نمایش داده می‌شود.
- فقط نمایشی است و ویرایش از انبار انجام می‌شود.
- کالاهای تولیدی با عنوان «تولید شده‌ها» نمایش داده می‌شوند.

### 10. نمای کلی مالی
- KPIها قابل کلیک شدند.
- آخرین فاکتورها تمام‌عرض/مرتب‌تر شدند.
- آخرین گردش بانک و صندوق اضافه شد.
- چک‌های باز و نزدیک اضافه شد.

## نکته مهم شماره‌گذاری شمسی
SQL شماره 030 باعث می‌شود اسناد جدید با سال شمسی ساخته شوند، مثل:

`RC-1405-00005`

به جای:

`RC-2026-00005`

این شامل شماره‌گذاری مالی، پرداخت‌ها، چک‌ها، ارجاعات، اسناد انبار، اسناد تولید و کالاهای تولیدی جدید است.

## نصب پچ
1. ZIP را Extract کن.
2. فایل‌ها را در پروژه اصلی کپی کن.
3. Replace / Overwrite را تأیید کن.
4. Commit و Push کن.
5. SQLهای 028، 029 و 030 را اجرا کن.
6. Deploy بگیر.

اگر SQL خطا داد، ادامه نده و عکس خطا را بفرست.
