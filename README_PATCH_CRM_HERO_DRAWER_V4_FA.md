# پچ V4 اصلاح CRM، هدر آبی سفارش‌ها و Drawer جزئیات

تاریخ آماده‌سازی: 2026-08-08

## تغییرات انجام‌شده

### 1. CRM مشتریان
در ستون عملیات فقط این گزینه‌ها باقی ماند:

- پرونده
- ویرایش
- غیرفعال

برای جلوگیری از تداخل نوشته‌ها، دکمه‌های عملیات به صورت عمودی زیر هم قرار گرفتند. عرض ستون‌های نام و تلفن هم بیشتر شد تا در حالت عادی نوشته‌ها روی هم نیفتند.

### 2. هدر آبی بخش سفارش‌ها
دکمه‌های هدر آبی سفارش‌ها به پایین/راست منتقل شدند و ترتیب آن‌ها این شد:

1. سفارش جدید
2. پیگیری CRM
3. مشتری/سرنخ
4. به‌روزرسانی

دکمه‌های خروجی Excel و چاپ/PDF بعد از این چهار گزینه باقی مانده‌اند.

### 3. مراحل سفارش
در کارت مراحل سفارش:

- کادر «تا تحویل نهایی» در پایین/راست کارت قرار گرفت.
- دکمه «جزئیات و عملیات» در پایین/چپ کارت قرار گرفت.
- با زدن «جزئیات و عملیات»، پنل جزئیات حتماً از سمت چپ باز می‌شود.

## Build
Build با `npm run build` موفق بود.

## نصب پچ
1. ZIP را Extract کن.
2. فایل‌ها را روی پروژه `otomasion3` کپی کن.
3. Replace / Overwrite را تأیید کن.
4. GitHub Desktop:
   `Commit to main`
5. سپس:
   `Push origin`
6. در Netlify اگر لازم بود Clear cache deploy بزن.
7. تست:
   `https://otomasion3.netlify.app/?v=crm-hero-drawer-v4`

این پچ SQL جدید ندارد.
