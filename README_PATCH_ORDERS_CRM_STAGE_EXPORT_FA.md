# پچ اصلاحات سفارش، CRM، مراحل، تاریخ و خروجی‌ها

تاریخ آماده‌سازی: 2026-08-07

## موارد اجراشده

1. عنوان برند در بالای برنامه بررسی شد و «اتوماسیون آریامان» صحیح است.
2. در جزئیات سفارش، بخش تاریخچه دارای اسکرول عمودی شد تا کارت سفارش بلند و دراز نشود.
3. در جدول مشتریان CRM ستون‌های «شهر»، «روش جذب» و «مسئول» از نمایش حذف شد تا جدول در عرض صفحه جا شود.
4. با لغو سفارش، سفارش از لیست‌های فعال سفارش‌ها، نمای کلی، مراحل سفارش، CRM و پیگیری‌های مرتبط سفارش حذف/مخفی می‌شود. حذف دیتابیس همچنان امن است و سفارش فقط لغو می‌شود.
5. نوار مراحل سفارش‌ها فشرده‌تر شد، رنگ مراحل و خط‌ها سبز شد، و داخل همان کارت جا می‌شود.
6. باکس موعد تحویل به شکل یک کادر کوچک در پایین/چپ کارت سفارش منتقل شد.
7. قابلیت ویرایش مشتری بعد از انتخاب مشتری در CRM اضافه شد.
8. در بخش موجودی/انبار سفارش‌ها سرچ اضافه شد.
9. بخش تنظیم مراحل سفارش عملیاتی‌تر شد:
   - انتخاب قالب
   - فعال/غیرفعال‌سازی قالب
   - ویرایش نام مرحله
   - ویرایش ترتیب مرحله
   - ویرایش مسئول مرحله
   - فعال/غیرفعال کردن مرحله
   - افزودن مرحله جدید
   - قالب‌های فعال در فرم ثبت سفارش قابل انتخاب هستند.
10. خروجی‌های PDF/Excel سفارش، CRM، مالی و انبار برنددار شدند و لوگو، سربرگ سرمه‌ای/طلایی و جدول مرتب دارند.
11. ورودی‌های تاریخ همچنان شمسی هستند و ورودی میلادی `type=date` در سورس React وجود ندارد.

## روش نصب پچ

1. ZIP را Extract کن.
2. پوشه‌های داخل آن را روی پروژه `otomasion3` کپی کن.
3. اگر پرسید Replace/Overwrite، تأیید کن.
4. GitHub Desktop را باز کن.
5. Summary بنویس:
   `orders crm stages export fixes`
6. Commit to main بزن.
7. Push origin بزن.
8. در Netlify در صورت نیاز Clear cache and deploy site بزن.
9. سایت را با این آدرس تست کن:
   `https://otomasion3.netlify.app/?v=orders-crm-stage-export-v1`

## تست سریع بعد از Deploy

- CRM: لیست مشتریان بدون ستون شهر/روش جذب/مسئول نمایش داده شود.
- CRM: یک مشتری را انتخاب کن و دکمه ویرایش مشتری را تست کن.
- سفارش‌ها: یک سفارش را لغو کن؛ باید از لیست‌های فعال حذف شود.
- مراحل سفارش: نوار مراحل باید سبز و بدون اسکرول افقی باشد.
- جزئیات سفارش: تاریخچه باید اسکرول عمودی داشته باشد.
- موجودی انبار سفارش‌ها: سرچ کالا را تست کن.
- تنظیم مراحل: یک مرحله را ویرایش کن یا مرحله جدید اضافه کن.
- Excel/PDF: خروجی‌ها باید سربرگ لوگودار اتوماسیون آریامان داشته باشند.

اگر در اجرای SQL یا عملیات آنلاین خطا دیدی، ادامه نده و عکس خطا را بفرست.
