# گزارش نهایی تغییرات پروژه

این بسته شامل اصلاحات سورس پروژه است و هیچ داده‌ای از دیتابیس در آن حذف یا بازسازی نشده است.

## سفارش‌ها و مراحل

- اصلاح KPIهای سفارش: باز، عقب‌افتاده و نزدیک تحویل فقط بر اساس سفارش‌های فعال محاسبه می‌شوند.
- سفارش‌های تکمیل‌شده در باز و عقب‌افتاده محاسبه نمی‌شوند.
- نمایش اولیه کارت‌های سفارش حداکثر ۱۰ مورد است.
- نمایش بیشتر، سفارش‌های باز و تکمیل‌شده را نشان می‌دهد؛ سفارش‌های لغوشده نمایش داده نمی‌شوند.
- فیلتر تاریخ ثبت سفارش در بخش مراحل اضافه شد.
- ستون ردیف در لیست سفارش‌ها اضافه شد.
- لیست سفارش‌ها دارای اسکرول کنترل‌شده است.
- نزدیک‌ترین تحویل‌ها نام مشتری، شماره سفارش، تاریخ موعد و روزهای تأخیر/مانده را نمایش می‌دهد.
- گزینه «ارسال شده و خروج از انبار» در جزئیات سفارش اضافه شد.

## ارسال و انبار

- Migration 074 برای ثبت یکتای ارسال هر سفارش و جلوگیری از ارسال تکراری.
- ثبت ارسال از فاکتور نهایی تأییدشده.
- دکمه حذف لیست ارسال، حذف ایمن/لغو نمایشی است و سند و کاردکس را حذف نمی‌کند.
- اصلاح دسته‌بندی گزارش انبار بر اساس دسته‌های واقعی موجود در کالاها.
- بخش ارزش کل انبار شامل ارزش تومانی جدید، ارزش پایه دلاری و ارزش پایه یوانی.
- نرخ دلار و یوان قابل ثبت و ذخیره در سیستم.
- Migration 076 برای ذخیره نرخ‌های سیستم.
- نرخ پایه دلار ۱۸۰۰۰۰ تومان و نرخ پایه یوان ۲۶۰۰۰ تومان است.

## حسابداری و صورت‌حساب

- صورت‌حساب کامل شخص شامل مانده اول دوره، فاکتورها، دریافت‌ها، پرداخت‌ها، بدهکار، بستانکار، مانده جاری و مانده نهایی.
- خلاصه جمع بدهکار، جمع بستانکار و مانده نهایی در بالای صورت‌حساب.
- Migration 075 برای View کامل صورت‌حساب.
- حذف نمایش UUID به‌جای شناسه ملی در PDF فاکتور.
- نمایش اطلاعات واقعی مشتری از پروفایل شخص در PDF.
- تلاش برای تک‌صفحه‌ای شدن PDF فاکتور در صورت کم بودن اقلام.

## کد مشتری

- Migrationهای 068 تا 073 مربوط به اصلاحات کد مشتری در پروژه قرار دارند.
- Migration 073 برای بازیابی نگاشت تأییدشده مشتریان آماده شده است.
- Migrationهای قبلی را بدون هماهنگی دوباره اجرا نکنید.

## استقرار

```bash
npm install
npm run build
git add .
git commit -m "Finalize automation workflow, customer codes, warehouse valuation and accounting reports"
git push origin main
```

سپس Migrationهای جدید را طبق ترتیب و با نسخه پشتیبان اجرا کنید:

```text
074_order_unique_shipment_toggle.sql
075_complete_party_statement.sql
076_warehouse_exchange_rates.sql
```

فایل‌های 068 تا 073 فقط طبق وضعیت فعلی دیتابیس و راهنمای قبلی اجرا شوند.
