# اصلاح حسابداری - ورود گروهی اشخاص/مشتریان از Excel

تاریخ: ۱۴۰۵/۰۵/۲۵

## درخواست
در بخش «اشخاص و صورت‌حساب‌ها»، امکان دریافت فایل Excel برای انتقال مشتریان/اشخاص از سیستم دیگر به اتوماسیون اضافه شود.

## اصلاح انجام‌شده
در بخش حسابداری → اشخاص و صورت‌حساب‌ها، دکمه‌های جدید اضافه شدند:

```txt
قالب Excel
ورود از Excel
```

## فایل نمونه Excel
فایل نمونه داخل پروژه قرار گرفت:

```txt
public/templates/finance_parties_import_template.xlsx
```

ستون‌های فایل نمونه:

```txt
نوع شخص
نام
تلفن
ایمیل
آدرس

یادداشت
```

## نوع شخص‌ها
مقادیر قابل قبول:

```txt
مشتری → customer
تأمین‌کننده / تامین‌کننده → supplier
کارمند → employee
سهامدار → shareholder
سایر → other
```

اگر نوع شخص خالی یا ناشناس باشد، پیش‌فرض `مشتری` ثبت می‌شود.

## روند کار
1. کاربر قالب Excel را دانلود می‌کند.
2. اطلاعات مشتریان/اشخاص را وارد می‌کند.
3. فایل Excel را آپلود می‌کند.
4. سیستم پیش‌نمایش ردیف‌های معتبر را نشان می‌دهد.
5. با زدن ثبت، همه ردیف‌ها در اشخاص مالی ثبت می‌شوند.
