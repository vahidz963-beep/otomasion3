# رفع مشکل باز شدن فرم دریافت/پرداخت زیر جزئیات فاکتور

## مشکل
در بخش مالی/حسابداری، وقتی از داخل جزئیات فاکتور روی «دریافت/پرداخت» زده می‌شد، فرم دریافت/پرداخت باز می‌شد اما زیر پنجره جزئیات فاکتور قرار می‌گرفت و درست دیده نمی‌شد.

## علت
`z-index` پنجره جزئیات فاکتور از `FinanceModal` بیشتر بود؛ بنابراین فرم جدید زیر پنجره قبلی نمایش داده می‌شد.

## اصلاح انجام‌شده
- لایه‌بندی Modalهای حسابداری اصلاح شد.
- از این به بعد فرم‌های جدید مثل:
  - دریافت/پرداخت
  - ارجاع
  - ویرایش/اصلاح فاکتور
  - فرم‌های تأیید مالی

  وقتی از داخل جزئیات فاکتور باز شوند، روی پنجره قبلی نمایش داده می‌شوند، نه زیر آن.

## فایل تغییرکرده
```txt
src/modules/accounting/AccountingModule.css
```

## تست
Build پروژه موفق بود:

```txt
npm run build
✓ built successfully
```

## نیاز به Deploy
این اصلاح کدی/ظاهری است و در Deploy نهایی فعال می‌شود.
