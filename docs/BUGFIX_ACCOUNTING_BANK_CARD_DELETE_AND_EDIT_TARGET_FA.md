# رفع حذف نشدن کارت‌های بانکی و بهبود کلیک ویرایش

## مشکل
در بخش مالی/حسابداری > صندوق و گردش حساب:

- کارت/حساب بانکی اضافه می‌شد اما با زدن حذف، حتی با ادمین، از لیست کارت‌ها حذف/مخفی نمی‌شد.
- دکمه ویرایش فقط پشت کارت بود و جای کلیک آن واضح و راحت نبود.

## علت
حذف امن کارت، مقدار `is_active=false` می‌کرد اما View گردش حساب هنوز حساب‌های غیرفعال را هم نمایش می‌داد. بنابراین عملیات حذف انجام می‌شد ولی کارت همچنان در لیست دیده می‌شد.

## اصلاحات انجام‌شده
- در کد، لیست کارت‌ها و حساب‌ها فقط موارد `is_active=true` را نمایش می‌دهد.
- Query حساب‌های بانکی فقط حساب‌های فعال را می‌خواند.
- دکمه حذف در Modal حذف، دلیل پیش‌فرض دارد تا مدیر راحت‌تر حذف را تأیید کند.
- روی خودِ روی کارت هم دو دکمه واضح اضافه شد:
  - ویرایش
  - حذف
- دکمه‌های پشت کارت هم باقی ماندند و کلیک‌پذیری‌شان بهتر شد.
- SQL جدید ساخته شد تا View `v_finance_account_turnover` هم فقط حساب/کارت فعال را نمایش دهد.
