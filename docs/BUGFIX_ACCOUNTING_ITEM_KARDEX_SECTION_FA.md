# رفع خطای کاردکس کالاها در حسابداری

## مشکل
با ورود به تب «کاردکس کالاها» در بخش مالی/حسابداری، صفحه با خطای زیر باز نمی‌شد:

```txt
ItemKardexSection is not defined
```

علت: در `AccountingModule.jsx` تب کاردکس به کامپوننت `ItemKardexSection` وصل شده بود، ولی خود کامپوننت در فایل تعریف نشده بود.

## اصلاحات انجام‌شده
- کامپوننت کامل `ItemKardexSection` اضافه شد.
- صفحه کاردکس کالاها بدون خطای نمایش باز می‌شود.
- امکانات زیر به کاردکس اضافه شد:
  - جست‌وجوی کالا با کد/نام/سند/شرح
  - فیلتر همه کالاها، کالای مشخص، ورود، خروج
  - کارت خلاصه ورود/خروج/تعداد گردش/آخرین قیمت فروش
  - انتخاب سریع کالا از لیست موجودی
  - جدول ریز گردش با مرتب‌سازی ستون‌ها
  - خروجی Excel
  - چاپ / PDF
- ظاهر صفحه با سبک مالی/حسابداری هماهنگ شد.

## فایل‌های تغییرکرده
```txt
src/modules/accounting/AccountingModule.jsx
src/modules/accounting/AccountingModule.css
```

## تست
Build با موفقیت انجام شد:

```txt
npm run build
✓ built successfully
```

## نکته
این اصلاح نیاز به SQL جدید ندارد؛ فقط باید کد Deploy شود.
