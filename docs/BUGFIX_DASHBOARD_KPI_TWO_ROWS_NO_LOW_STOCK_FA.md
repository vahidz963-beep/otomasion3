# اصلاح چیدمان KPIهای داشبورد

## درخواست
- KPIهای داشبورد در دو ردیف تمیز نمایش داده شوند.
- KPI «کمبودهای انبار / کم‌موجودی» از کارت‌های اصلی داشبورد حذف شود.

## اصلاحات انجام‌شده
- کارت KPI «کم‌موجودی» از بخش KPIهای بالای داشبورد حذف شد.
- اطلاعات کم‌موجودی همچنان در جدول «موجودی‌های کم» برای نقش انبار قابل مشاهده است.
- چیدمان KPIهای داشبورد روی دسکتاپ به ۵ ستون تنظیم شد تا برای داشبورد مدیریتی در دو ردیف مرتب نمایش داده شود.
- ارتفاع کارت‌ها همسان‌تر شد.
- در تبلت و موبایل چیدمان واکنش‌گرا باقی ماند.

## فایل‌های تغییرکرده
```txt
src/modules/dashboard/Dashboard.jsx
src/modules/dashboard/Dashboard.css
```

## تست

```txt

✓ built successfully
```
