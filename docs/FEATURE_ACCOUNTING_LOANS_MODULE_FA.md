# قابلیت جدید حسابداری - بخش وام‌ها

تاریخ: ۱۴۰۵/۰۵/۲۶

## درخواست
در بخش مالی و حسابداری، بعد از بخش «سود سفارش‌ها»، یک بخش جدید به نام «وام‌ها» اضافه شود.

## امکانات اضافه‌شده

### ۱. تب جدید وام‌ها
در حسابداری، تب جدید اضافه شد:

```txt
وام‌ها
```

جایگاه: بعد از «سود سفارش‌ها» و قبل از «دوره مالی».

### ۲. لیست تمام وام‌های شرکت
در این بخش، تمام وام‌های شرکت نمایش داده می‌شوند.

برای هر وام:

- شماره وام
- عنوان وام
- وام‌دهنده / بانک
- اصل مبلغ وام
- جمع قابل پرداخت
- تعداد اقساط
- مانده بدهی
- اقساط پرداخت‌شده
- اقساط باقی‌مانده
- اقساط عقب‌افتاده
- تاریخ سررسید بعدی

### ۳. جمع بدهی وام‌های شرکت
بالای بخش وام‌ها KPIهای زیر نمایش داده می‌شود:

- جمع بدهی وام‌ها
- اقساط عقب‌افتاده
- پرداخت‌شده
- سررسید این ماه

### ۴. افزودن وام جدید
دکمه جدید:

```txt
+ افزودن وام
```

فرم اطلاعات وام شامل:

- عنوان وام
- وام‌دهنده / بانک
- نام بانک
- نوع وام‌دهنده
- مبلغ اصل وام
- جمع قابل پرداخت
- تعداد ماه / اقساط
- فاصله اقساط ماهانه
- نرخ سود
- تاریخ دریافت وام
- اولین سررسید
- جزئیات و توضیحات

### ۵. ساخت خودکار اقساط
بعد از ثبت وام، سیستم بر اساس:

- تعداد اقساط
- فاصله اقساط
- تاریخ اولین سررسید
- جمع قابل پرداخت

برنامه اقساط را می‌سازد.

### ۶. انتخاب هر وام و مشاهده اقساط
با کلیک روی هر کارت وام، اقساط همان وام نمایش داده می‌شود.

### ۷. ثبت پرداخت قسط
برای هر قسط، دکمه زیر وجود دارد:

```txt
ثبت پرداخت
```

در این فرم می‌توان:

- مبلغ پرداختی
- تاریخ پرداخت
- سند پرداخت بانک/صندوق
- یادداشت

را ثبت کرد.

### ۸. اتصال قسط به سند پرداخت
کاربر می‌تواند از بین پرداخت‌های ثبت‌شده در صندوق و بانک، سند پرداخت مربوط به قسط را انتخاب کند.

### ۹. وضعیت اقساط
وضعیت‌ها:

```txt
در انتظار
پرداخت‌شده
عقب‌افتاده
لغو
```

اقساطی که سررسیدشان گذشته و پرداخت نشده‌اند به صورت عقب‌افتاده نمایش داده می‌شوند.
