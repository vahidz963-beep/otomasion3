# راهنمای شروع واقعی شرکت و پاک‌سازی داده‌های تستی

## فایل اصلی پاک‌سازی

```txt
supabase/maintenance/RESET_TO_REAL_COMPANY_START_2026-08-18.sql
```

این فایل برای اجرای دستی در Supabase SQL Editor است و نباید به عنوان migration خودکار اجرا شود.

## قبل از اجرا

1. از Supabase Backup بگیرید.
2. اگر فایل تستی در Storage دارید، اول اگر لازم است دانلود کنید.
3. مطمئن شوید همه کاربران از سیستم خارج هستند.
4. مطمئن شوید کاربر مدیر در جدول `profiles` فعال و admin است.

## چه چیزهایی پاک می‌شود؟

- مشتری‌ها و اشخاص مالی
- سفارش‌ها و اقلام سفارش
- فاکتورها و اسناد حسابداری
- پرداخت‌ها، چک‌ها، وام‌ها
- کالاها و اسناد انبار
- تولید و R&D
- ارجاعات، فایل‌های مشترک، CRM و لاگ‌های عملیاتی
- کارت‌ها و حساب‌های بانکی تستی

## چه چیزهایی باقی می‌ماند؟

- کاربران و نقش‌ها
- تنظیمات پایه سیستم
- قالب مراحل سفارش/تولید/R&D
- قوانین شماره‌گذاری
- حساب‌های پایه حسابداری
- سال مالی و دوره‌های مالی پایه

## بعد از اجرا

ترتیب ورود اطلاعات واقعی:

1. کاربران و نقش‌ها را چک کنید.
2. کالاهای واقعی را از Excel وارد کنید.
3. موجودی اول دوره را وارد کنید.
4. اشخاص مالی/مشتری‌ها را از Excel وارد کنید.
5. حساب‌ها و کارت‌های بانکی واقعی را ثبت کنید.
6. چک‌ها و وام‌های باز واقعی را وارد کنید.
7. فرمول‌های تولید را تعریف کنید.
8. سفارش‌های واقعی را ثبت کنید.
9. فاکتور و پرداخت واقعی را شروع کنید.

## نکته Storage

SQL فقط متادیتای فایل‌ها در جدول `shared_files` را پاک می‌کند. برای پاک‌کردن خود فایل‌های آپلودی، از Supabase Dashboard > Storage محتوای bucketهای زیر را پاک کنید:

```txt
automation-shared-files
order-attachments
```
