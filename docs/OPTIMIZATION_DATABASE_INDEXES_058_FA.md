# بهینه‌سازی سبک دیتابیس - SQL 058

## هدف
این مرحله برای آماده‌سازی نسخه تست داخلی و کاهش فشار روی Supabase ساخته شد.

## فایل SQL
```txt
supabase/migrations/058_database_performance_indexes_and_analyze.sql
```

## چه کاری انجام می‌دهد؟
- روی جدول‌های پرتکرار Index اضافه می‌کند.
- سرعت لیست‌ها و گزارش‌های زیر بهتر می‌شود:
  - داشبورد
  - سفارش‌ها
  - مالی/حسابداری
  - فاکتورها و پرداخت‌ها
  - انبار و کاردکس
  - تولید
  - R&D
  - ارجاعات
  - کاربران
- بعد از ساخت Indexها، دستور `ANALYZE` اجرا می‌شود تا PostgreSQL آمار جدید جدول‌ها را بشناسد.

## چه چیزی را تغییر نمی‌دهد؟
- هیچ داده‌ای پاک نمی‌کند.
- هیچ رکوردی را ویرایش نمی‌کند.
- RLS و نقش‌ها را تغییر نمی‌دهد.
- ساختار اصلی جدول‌ها را عوض نمی‌کند.
