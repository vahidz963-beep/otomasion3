# اصلاح عرض دو بخش مهم نمای کلی تولید

## مشکل
در تب «نمای کلی» بخش تولید، دو کارت/جدول اصلی:

- سفارش‌های آماده تأیید
- تولیدهای فعال

به شکل مساوی کل عرض ردیف را پر نمی‌کردند و در صفحه فضای خالی/نامتوازن دیده می‌شد.

## اصلاح انجام‌شده
- برای ردیف نمای کلی تولید کلاس اختصاصی `production-overview-grid` اضافه شد.
- دو بخش اصلی دقیقاً دو ستون مساوی شدند:
  - هر کدام ۵۰٪ عرض ردیف
  - فاصله بین دو جدول حفظ شد
  - فضای اضافی بین جدول‌ها حذف شد
- کارت‌ها داخل Grid کامل کشیده می‌شوند و ارتفاع و ظاهرشان منظم‌تر است.
- در موبایل/عرض کم، دو جدول به صورت تک‌ستونه زیر هم نمایش داده می‌شوند تا صفحه به هم نریزد.

## فایل‌های تغییرکرده
```txt
src/modules/production/ProductionModule.jsx
src/modules/production/ProductionModule.css
```

## تست
Build پروژه با موفقیت انجام شد:

```txt
npm run build
✓ built successfully
```
