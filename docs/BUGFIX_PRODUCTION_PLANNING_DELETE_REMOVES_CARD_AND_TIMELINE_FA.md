# اصلاح تولید - حذف کامل سفارش از برنامه‌ریزی

تاریخ: ۱۴۰۵/۰۵/۲۵

## مشکل
در بخش تولید، تب «برنامه‌ریزی تولید»، بعد از زدن «حذف از برنامه»، سفارش از برنامه واقعاً حذف می‌شد اما هنوز در صفحه برنامه‌ریزی دیده می‌شد:

- روی نمودار زمانی
- در کارت‌های برنامه‌ریزی پایین صفحه

## علت
صفحه برنامه‌ریزی همه سفارش‌های تولیدی را نمایش می‌داد، حتی سفارش‌هایی که دیگر برنامه فعال نداشتند.

## اصلاح انجام‌شده
در تب برنامه‌ریزی، فقط سفارش‌هایی نمایش داده می‌شوند که واقعاً برنامه فعال دارند:

- رکورد در `production_plans` داشته باشند
- یا `planned_start` / `planned_end` روی سفارش تولیدی داشته باشند

بعد از اجرای حذف از برنامه، تابع دیتابیس این موارد را پاک می‌کند:

```txt
production_plans
planned_start
planned_end
work_days
labor_people
total_man_hours
```

بنابراین بعد از Refresh، سفارش حذف‌شده دیگر در برنامه‌ریزی نمایش داده نمی‌شود.

## نتیجه
با زدن «حذف از برنامه»:

```txt
از نمودار زمانی حذف می‌شود
از کارت برنامه‌ریزی حذف می‌شود
ولی خود سفارش تولیدی در مراحل تولید باقی می‌ماند
```

## فایل تغییر داده‌شده

```txt
src/modules/production/ProductionModule.jsx
```

## SQL لازم دارد؟
خیر. تابع دیتابیس حذف برنامه از قبل وجود دارد:

```sql
fn_production_delete_plan(uuid)
```
