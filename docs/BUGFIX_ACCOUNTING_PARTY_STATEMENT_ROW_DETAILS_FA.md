# اصلاح حسابداری - نمایش جزئیات ردیف‌های صورت‌حساب شخص

تاریخ: ۱۴۰۵/۰۵/۲۶

## درخواست
در بخش «اشخاص و صورت‌حساب‌ها»، با کلیک روی هر ردیف صورت‌حساب شخص، جزئیات همان سند وسط صفحه باز شود.

موارد قابل کلیک:

- فاکتور فروش
- فاکتور خرید
- پیش‌فاکتور
- سند دریافت
- سند پرداخت
- سایر اسناد مالی مرتبط

## اصلاح انجام‌شده

### ۱. ردیف‌های صورت‌حساب کلیک‌پذیر شدند
در جدول صورت‌حساب، ستون جدید اضافه شد:

```txt
جزئیات
```

و هر ردیفی که به سند مالی یا دریافت/پرداخت وصل باشد، دکمه «مشاهده» دارد.

### ۲. نمایش جزئیات فاکتور وسط صفحه
اگر ردیف مربوط به فاکتور یا سند مالی باشد، همان کامپوننت جزئیات فاکتور وسط صفحه باز می‌شود.

امکانات داخل آن:

- اقلام فاکتور
- پرداخت‌های مرتبط
- تاریخچه سند
- چاپ
- ویرایش / ارجاع / عملیات مالی موجود

### ۳. نمایش جزئیات دریافت/پرداخت وسط صفحه
اگر ردیف مربوط به دریافت یا پرداخت باشد، Modal جزئیات پرداخت/دریافت باز می‌شود و این اطلاعات را نشان می‌دهد:

- شماره سند پرداخت
- نوع دریافت/پرداخت
- تاریخ
- مبلغ
- حساب
- بانک
- شخص
- روش پرداخت
- شماره سفارش
- شرح سند

### ۴. قابلیت بستن
هر کادر جزئیات، دکمه بستن دارد و با کلیک بیرون Modal نیز بسته می‌شود.

## فایل‌های تغییر داده‌شده

```txt
src/hooks/useAccountingData.js
src/modules/accounting/AccountingModule.jsx
src/modules/accounting/AccountingModule.css
```
