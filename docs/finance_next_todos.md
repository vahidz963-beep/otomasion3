# یادداشت موارد مرحله بعد ماژول مالی

طبق تصمیم فعلی، این موارد فعلاً نگه داشته می‌شوند و بعد از تکمیل نسخه نمایشی/فرم‌های اصلی به آن‌ها برمی‌گردیم.

## بعداً اضافه شود

### 2) کنترل دسترسی دقیق‌تر
- فروش فقط فاکتورهای مشتری/سفارش خودش را ببیند.
- حسابدار همه اسناد مالی را ببیند.
- تولید فقط هزینه‌های تولید خودش را ثبت/ارجاع کند.
- انبار فقط فاکتورهای خرید/ورود کالا و مغایرت‌ها را ارجاع دهد.
- مدیر کل گزارش کامل و دسترسی مدیریتی داشته باشد.

### 3) گزارش‌های مدیریتی بیشتر
- فروش ماهانه
- هزینه ماهانه
- سود و زیان مشتری
- سود و زیان مسیر سفارش: بازرگانی / R&D / تولید
- بدهکاران سررسید گذشته
- بستانکاران
- چک‌های نزدیک سررسید
- گردش حساب رسمی / غیررسمی
- مغایرت حساب‌ها

### 5) اتصال واقعی به بخش‌های دیگر
- سفارش → ساخت فاکتور
- تولید → ثبت هزینه تولید
- R&D → ثبت هزینه نمونه‌سازی
- انبار → ثبت فاکتور خرید / هزینه انبار
- مالی → ارجاع پیگیری تسویه به فروش

### 6) مدیریت مالیات و رسمی/غیررسمی
- فاکتور رسمی / غیررسمی
- حساب رسمی / غیررسمی
- گزارش جداگانه رسمی و غیررسمی
- VAT فقط برای اسناد رسمی
- خروجی مالیاتی فقط از حساب/فاکتور رسمی

### 8) هشدارها و یادآوری‌های پیشرفته
- فاکتور سررسید گذشته
- چک نزدیک سررسید
- مشتری بدهکار مهم
- پرداخت تأمین‌کننده نزدیک موعد
- فاکتور بدون پرداخت
- سفارش کم‌سود/زیان‌ده
- ارجاع مالی بی‌پاسخ
