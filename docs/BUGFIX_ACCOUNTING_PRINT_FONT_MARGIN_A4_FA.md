# بزرگ‌کردن فونت چاپ و فاصله یک‌سانتی از حاشیه A4

## درخواست
- فونت خروجی‌های چاپ فاکتور و صورت‌حساب ۳ تا ۴ درجه بزرگ‌تر شود.
- دور تا دور چاپ روی کاغذ A4 حداقل حدود ۱ سانتی‌متر فاصله سفید داشته باشد.

## اصلاحات انجام‌شده
- حاشیه چاپ `@page` از ۷ میلی‌متر به ۱۰ میلی‌متر افزایش یافت.
- کادر اصلی خروجی کوچک‌تر شد تا داخل حاشیه ۱ سانتی‌متری A4 جا شود:
  - افقی: ۲۷۷ میلی‌متر
  - عمودی: ۱۹۰ میلی‌متر
- سایز فونت عمومی چاپ بزرگ‌تر شد.
- سایز فونت جدول‌ها، اعداد، مبالغ، توضیحات، جمع‌ها و امضاها بزرگ‌تر شد.
- فونت جمع‌ها و مبالغ همچنان Bold و خواناتر نگه داشته شد.

## فایل تغییرکرده
```txt
src/lib/financeApi.js
```

## تست
Build پروژه با موفقیت انجام شد:

```txt
npm install && npm run build
✓ built successfully
```
