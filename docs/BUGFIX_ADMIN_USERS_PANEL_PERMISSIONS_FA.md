# رفع مشکل مدیریت کاربران و تشخیص ادمین

## مشکل
در صفحه «مدیریت کاربران» پیام زیر نمایش داده می‌شد و لیست کاربران/ثبت کاربر/تغییر نقش انجام نمی‌شد:

```txt
خطا: فقط مدیر کل مجاز به این عملیات است
```

علت محتمل این بود که ساختار دیتابیس بخش کاربران با نسخه جدید هماهنگ نبود؛ مخصوصاً ستون `additional_roles` یا نقش `sales_manager` در بعضی دیتابیس‌ها وجود نداشت و تابع سروری Netlify کاربر مدیر را درست تشخیص نمی‌داد.

## اصلاحات انجام‌شده
- تابع سروری `admin-users` پایدارتر شد و اگر ستون `additional_roles` هنوز در دیتابیس نباشد، با ساختار قدیمی هم لیست کاربران را می‌خواند.
- پیام‌های خطا واضح‌تر شدند تا مشخص شود مشکل از نقش، پروفایل، SQL یا متغیرهای Netlify است.
- فرم ایجاد کاربر فقط در صورت ثبت موفق بسته می‌شود.
- حذف کاربر و تغییر رمز عبور دیگر با `prompt/confirm` مرورگر نیست و با Modal داخلی شیک انجام می‌شود.
- دکمه «بارگذاری مجدد» و پیام خالی بودن جدول اضافه شد.
- SQL جدید `047_admin_users_panel_stability.sql` برای کامل‌کردن ساختار کاربران و دسترسی‌ها اضافه شد.

## فایل‌های تغییرکرده
```txt
netlify/functions/admin-users.js
src/components/admin/AdminUserPanel.jsx
src/components/admin/AdminUserPanel.css
supabase/migrations/047_admin_users_panel_stability.sql
```

## کار لازم بعد از Deploy
فایل SQL زیر را کامل در Supabase اجرا کنید:

```txt
supabase/migrations/047_admin_users_panel_stability.sql
```

اگر SQL خطا داد، ادامه ندهید و متن/عکس خطا را بفرستید.
