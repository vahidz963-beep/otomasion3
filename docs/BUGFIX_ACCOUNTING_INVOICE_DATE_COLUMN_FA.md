# اصلاح حسابداری - ستون تاریخ در لیست فاکتورها

تاریخ: ۱۴۰۵/۰۵/۲۵

## درخواست
در بخش فاکتورها، ستون تاریخ باید بعد از شماره فاکتور اضافه شود و مثل بقیه ستون‌ها قابلیت مرتب‌سازی داشته باشد.

## اصلاح انجام‌شده
در جدول‌های فاکتورها، ستون زیر بعد از «شماره» اضافه شد:

```txt
تاریخ
```

این ستون از فیلد زیر خوانده می‌شود:

```txt
issue_date
```

و با فرمت شمسی نمایش داده می‌شود.

## مرتب‌سازی
سرستون «تاریخ» مثل بقیه ستون‌ها دکمه Sort دارد و با کلیک روی آن، فاکتورها بر اساس تاریخ صعودی/نزولی مرتب می‌شوند.

## خروجی Excel
خروجی Excel فاکتورها هم اصلاح شد و ستون تاریخ بعد از شماره اضافه شد.

