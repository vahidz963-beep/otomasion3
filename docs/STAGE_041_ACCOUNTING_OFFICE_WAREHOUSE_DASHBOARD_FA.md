# مرحله ۰۴۱ - بهبود حسابداری، اداری، انبار و داشبورد مدیرکل

تاریخ انجام: ۱۴۰۵/۰۵/۲۴

## بخش حسابداری

### ۱. جداسازی لیست فاکتورها
در تب فاکتورها، لیست‌ها جدا شدند:

- پیش‌فاکتورهای فروش
- فاکتورهای فروش
- فاکتورهای خرید و هزینه
- سایر اسناد مالی در صورت وجود

### ۲. جزئیات فاکتور وسط صفحه
با کلیک روی هر ردیف فاکتور، جزئیات در Modal وسط صفحه باز می‌شود.

در این Modal:

- اقلام سند
- پرداخت‌های مرتبط
- تاریخچه سند
- ثبت حسابداری
- ویرایش
- تبدیل پیش‌فاکتور
- برگشتی
- ابطال
- چاپ شرکتی / رسمی
- ارجاع

قابل انجام است.

### ۳. ویرایش فاکتور تأییدشده
اگر فاکتور قبلاً تأیید یا ثبت شده باشد، قبل از ویرایش یک تأیید شیک داخلی نمایش داده می‌شود:

```txt
آیا مایل هستید بعد از ویرایش، اسناد مرتبط مثل خروج/ورود انبار و سندهای مربوط نیز متناسب با فاکتور اصلاح شوند؟
```

در صورت تأیید، تابع زیر برای همگام‌سازی دوباره اسناد فراخوانی می‌شود:

```sql
public.fn_finance_reissue_inventory_for_document(uuid,text)
```

### ۴. برگشتی و ابطال فاکتور
SQL مرحله ۰۴۱ تابع برگشتی را بازنویسی می‌کند تا برای فاکتور برگشتی، سند برگشت ورود انبار نیز ساخته شود.

### ۵. کاردکس کالا در Modal وسط صفحه
در حسابداری، با کلیک روی هر کالا، کاردکس آن در Modal وسط صفحه باز می‌شود.

اطلاعات تکمیلی افزوده‌شده:

- مشتری/خریدار
- سند مالی
- سند انبار
- قیمت/ارزش
- شرح حرکت

## بخش انبار

### لیست ارسال‌شده‌ها
تب جدید اضافه شد:

```txt
لیست ارسال‌شده‌ها
```

امکانات:

- ثبت ارسال دستی
- ویرایش ارسال
- ثبت خودکار از سند خروج انبار / فاکتور نهایی
- فیلتر تاریخ
- فیلتر مبلغ
- فیلتر وضعیت
- سرچ مشتری/کالا/فاکتور
- مرتب‌سازی بر اساس ستون‌ها
- خروجی Excel
- چاپ/PDF حرفه‌ای

SQL جدید:

```sql
public.warehouse_shipments
public.v_warehouse_shipment_overview
public.fn_warehouse_upsert_shipment_from_document(uuid)
```

## داشبورد مدیرکل

### اصلاح سفارش‌های تکمیل‌شده
در محاسبه تکمیل‌شده‌ها، علاوه بر وضعیت خود سفارش، وضعیت تکمیل تولید و R&D مرتبط نیز لحاظ می‌شود.

### جدول پیش‌بینی وصولی ۱۰ روز آینده
زیر دو نمودار بالای داشبورد، جدول جدید اضافه شد:

```txt
پیش‌بینی وصولی ۱۰ روز آینده
```

ستون‌ها:

- مشتری
- سفارش
- تاریخ پیش‌بینی پرداخت
- مبلغ قابل وصول
- مرحله / پیشرفت
- وضعیت نزدیک بودن

SQL جدید:

```sql
public.v_finance_receivable_forecast
```

## بخش اداری

بخش اداری حرفه‌ای‌تر شد:

- ثبت/ویرایش نامه
- ثبت/ویرایش جلسه و صورتجلسه
- ثبت/ویرایش سند اداری
- کارتابل حرفه‌ای‌تر
- مرخصی و حضور حرفه‌ای‌تر
- درخواست مرخصی
- وضعیت تأیید اداری، تأیید نهایی، رد شده
- ارجاع اداری با sourceModule=`office`

## ارجاعات

### مقصد اداری اضافه شد
در مقصدهای ارجاع، گزینه اداری اضافه شد:

```txt
office → اداری
```

### درخواست مرخصی در هر بخش
در پنل ارجاعات هر ماژول، دکمه جدید اضافه شد:

```txt
درخواست مرخصی
```

با کلیک روی آن، فرم ارجاع با مقصد اداری و متن پیش‌فرض درخواست مرخصی آماده می‌شود.
