# اصلاح R&D - حذف سفارش از هزینه‌ها بعد از پایان پروژه

تاریخ: ۱۴۰۵/۰۵/۲۵

## مشکل
در تب هزینه‌های R&D، بعد از پایان پروژه/سفارش، گزینه‌ای برای حذف آن پروژه از لیست هزینه‌ها وجود نداشت.

## اصلاح انجام‌شده
- در کارت هر پروژه در تب «هزینه‌ها»، دکمه جدید اضافه شد:

```txt
حذف سفارش
```

- این دکمه فقط وقتی فعال می‌شود که پروژه به پایان رسیده باشد:
  - `status = approved`
  - یا `status = sent_to_production`
  - یا `delivery_status = completed`
  - یا `progress_percent >= 100`

- برای پروژه‌های در جریان، دکمه غیرفعال است و توضیح نمایش داده می‌شود:

```txt
تا پایان مراحل پروژه، حذف سفارش از هزینه‌ها غیرفعال است.
```

## حذف امن
حذف به‌صورت واقعی انجام نمی‌شود. پروژه به وضعیت زیر می‌رود:

```txt
archived
```

یعنی تاریخچه و هزینه‌ها حفظ می‌شوند، اما پروژه از لیست هزینه‌ها خارج می‌شود.

## فایل‌های تغییر داده‌شده

```txt
src/lib/rndApi.js
src/modules/rnd/RnDModule.jsx
src/modules/rnd/RnDModule.css
```

## SQL لازم دارد؟
خیر. ستون status و مقدار archived از قبل وجود دارد.
