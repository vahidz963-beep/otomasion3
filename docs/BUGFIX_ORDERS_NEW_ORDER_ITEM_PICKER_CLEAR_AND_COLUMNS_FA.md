# اصلاح ستون‌های کالا و ضربدر پاک‌کردن در ثبت سفارش جدید

## درخواست
در بخش سفارش‌ها، فرم «ثبت سفارش جدید»:

- ضربدر پاک‌کردن جستجوی کالا هنوز سمت راست بود و روی متن می‌افتاد.
- ستون جستجوی کالا باید ستون اول باشد و بعد از آن ستون شرح کالا بیاید.

## اصلاحات انجام‌شده
- در جدول اقلام سفارش جدید، جای ستون‌ها عوض شد:
  1. کد/نام کالا
  2. شرح کالا
  3. تعداد
  4. واحد
  5. فی ریال
- ضربدر پاک‌کردن ProductPicker در فرم ثبت سفارش جدید با CSS اختصاصی به سمت چپ منتقل شد.
- Padding ورودی جستجوی کالا اصلاح شد تا متن با ضربدر تداخل نداشته باشد.
- عرض ستون جستجوی کالا و شرح کالا بهتر تنظیم شد.

## فایل‌های تغییرکرده

```txt
src/modules/orders/OrdersModule.css
```
