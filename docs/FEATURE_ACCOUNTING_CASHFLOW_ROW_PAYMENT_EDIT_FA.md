# افزودن ویرایش ردیفی دریافت/پرداخت در صندوق و گردش حساب

## تغییر انجام‌شده
در بخش «حسابداری > صندوق و گردش حساب» برای هر ردیف دریافت/پرداخت یک دکمه گرد با آیکن مداد اضافه شد.

## قابلیت‌ها
- دکمه ویرایش در هر ردیف جدول گردش حساب نمایش داده می‌شود.
- شکل دکمه مثل دکمه‌های کوچک روی کارت‌های بانکی طراحی شده است.
- با زدن دکمه، اطلاعات کامل سند دریافت/پرداخت از دیتابیس خوانده می‌شود.
- سندهای دستی دریافت، پرداخت، هزینه، درآمد و پرداخت‌های مرتبط با فاکتور قابل ویرایش هستند.
- اگر سند به فاکتور وصل باشد، ارتباط فاکتور هنگام ویرایش حفظ می‌شود.
- بعد از ذخیره ویرایش، سند حسابداری قبلی پرداخت باطل و سند حسابداری جدید براساس اطلاعات اصلاح‌شده ثبت می‌شود.
- برای اسناد ساخته‌شده از بخش‌های دیگر مثل چک، حقوق یا اقساط، برای جلوگیری از خراب شدن سوابق، سیستم پیام می‌دهد که باید از همان بخش اصلی اصلاح شوند.
