# اصلاح حسابداری - کارت‌های بانکی، ویرایش و حذف با تأیید مدیر

تاریخ: ۱۴۰۵/۰۵/۲۶

## مشکلات
در بخش صندوق و گردش حساب:

1. گزینه ویرایش کارت‌ها واضح دیده نمی‌شد.
2. اطلاعات پشت کارت، مثل شماره شبا، از کادر بیرون می‌زد.
3. حذف کارت باید فقط با اجازه مدیر کل باشد.
4. کارت‌ها از نظر ظاهری یک‌شکل بودند و نیاز به تنوع داشتند.

## اصلاحات انجام‌شده

### ۱. دکمه ویرایش پشت هر کارت
در پشت کارت بانکی، دکمه واضح اضافه شد:

```txt
ویرایش کارت
```

### ۲. دکمه حذف کارت
در پشت کارت دکمه زیر اضافه شد:

```txt
حذف کارت
```

### ۳. حذف فقط با مدیر کل
اگر کاربر مدیر کل نباشد، هنگام حذف پیام می‌گیرد که حذف کارت فقط با دسترسی مدیر کل مجاز است.

اگر مدیر کل باشد، Modal تأیید باز می‌شود و دلیل حذف/غیرفعال‌سازی را می‌پرسد.

### ۴. حذف امن
کارت/حساب واقعاً از دیتابیس پاک نمی‌شود، بلکه غیرفعال می‌شود:

```txt
is_active = false
```

تا تاریخچه پرداخت‌ها حفظ شود.

### ۵. جا شدن اطلاعات پشت کارت
پشت کارت بازطراحی شد:

- اطلاعات داخل کادر می‌مانند.
- شماره شبا و شماره حساب wrap می‌شوند.
- پشت کارت اسکرول داخلی دارد اگر اطلاعات زیاد باشد.
- دکمه‌ها همیشه پایین کارت و داخل کادر باقی می‌مانند.

### ۶. ظاهر متنوع کارت‌ها
روی کارت‌ها ۶ طرح/رنگ مختلف اضافه شد تا همه کارت‌ها یک شکل نباشند.
