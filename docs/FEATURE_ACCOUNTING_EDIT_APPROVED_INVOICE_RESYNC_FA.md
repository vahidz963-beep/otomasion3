# امکان اصلاح فاکتور تأییدشده و همگام‌سازی اسناد وابسته

## درخواست
در بخش مالی/حسابداری، فاکتورهایی که تأیید شده‌اند یا سند حسابداری برای آن‌ها ثبت شده است باید راه اصلاح داشته باشند. بعد از اصلاح هم اسناد وابسته مثل سند حسابداری و خروج انبار باید دوباره مطابق نسخه اصلاح‌شده ساخته/همگام شوند.

## اصلاحات انجام‌شده
- در جدول فاکتورها برای اسناد غیرباطل دکمه جدید اضافه شد:
  - `ویرایش` برای پیش‌نویس‌ها
  - `اصلاح` برای فاکتورهای تأییدشده/ثبت‌شده
- داخل پنجره جزئیات فاکتور هم دکمه `ویرایش / اصلاح فاکتور` برای فاکتورهای تأییدشده نمایش داده می‌شود.
- هنگام اصلاح فاکتور تأییدشده، سیستم قبل از ذخیره نهایی یک Modal تأیید باز می‌کند و دلیل اصلاح را می‌گیرد.
- بعد از اصلاح فاکتور:
  - جمع‌ها دوباره محاسبه می‌شوند.
  - سند حسابداری قبلی فاکتور `void` می‌شود.
  - سند حسابداری جدید از روی مبالغ و ردیف‌های اصلاح‌شده ثبت می‌شود.
  - اگر فاکتور فروش باشد، سند خروج انبار قبلی لغو می‌شود و خروج انبار جدید با ردیف‌های اصلاح‌شده ساخته می‌شود.
- برای جلوگیری از به‌هم‌ریختن ارتباطات اسناد وابسته، در اصلاح فاکتور تأییدشده، نوع سند ثابت می‌ماند و فقط محتوا/اقلام/مبالغ/شخص/تاریخ قابل اصلاح است.
