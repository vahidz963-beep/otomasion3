# رفع خروج ناخواسته کاربر و افزودن Keep Alive / خروج بعد از ۶۰ دقیقه عدم فعالیت

## مشکل
کاربر هنگام کار با سیستم، ثبت فاکتور یا ثبت سند، بعد از مدتی از سیستم خارج می‌شد.

## علت محتمل
Supabase برای امنیت، توکن دسترسی را دوره‌ای منقضی می‌کند. اگر به‌خاطر اینترنت ضعیف، فیلترشکن، خوابیدن تب مرورگر یا عدم اجرای درست auto-refresh، توکن به‌موقع تمدید نشود، کاربر ممکن است ناخواسته از سیستم خارج شود.

اگر JWT expiry روی ۱۵ دقیقه تنظیم شده باشد، خود عدد ۱۵ دقیقه فقط زمان انقضای access token است و معمولاً باید خودکار تمدید شود؛ اما در شرایط شبکه ناپایدار ممکن است تمدید انجام نشود.

## اصلاح انجام‌شده
در `AuthProvider` سیستم فعالیت کاربر اضافه شد:

- کلیک
- تایپ
- اسکرول
- حرکت موس
- لمس صفحه
- فوکوس پنجره
- برگشتن به تب مرورگر

تا وقتی کاربر فعال است، سیستم هر چند دقیقه Session را تمدید می‌کند.

اگر هیچ فعالیتی انجام نشود، بعد از ۶۰ دقیقه کاربر از سیستم خارج می‌شود.
