# اصلاح فونت اعداد و ستون‌های صورت‌حساب - نسخه نمونه V3

## اصلاحات انجام‌شده
- فونت اعداد در خروجی‌های چاپ مالی از فونت لاتین/نامتجانس به فونت فارسی هماهنگ تغییر کرد.
- برای مبالغ، اعداد، جمع‌ها و مانده‌ها فونت یکسان و تمیزتر تنظیم شد.
- اعداد جمع و مانده کمی بزرگ‌تر و Bold باقی ماندند.
- در صورت‌حساب اشخاص، ستون جداگانه «شماره» حذف شد.
- شماره سند داخل ستون «شرح / شماره سند» قرار گرفت.
- بخش چهارخانه پایین صورت‌حساب حذف شد چون جمع و مانده نهایی در سطر آخر جدول نوشته می‌شود.
- خطوط بالای امضاها حذف شدند.
- فایل نمونه جدید ساخته شد:

```txt
accounting_print_preview_samples_v3.html
```

## فایل‌های تغییرکرده
```txt
src/lib/financeApi.js
src/modules/accounting/AccountingModule.jsx
accounting_print_preview_samples_v3.html
```

## تست
Build پروژه با موفقیت انجام شد:

```txt
npm install && npm run build
✓ built successfully
```
