# راهنمای آپلود نسخه کامل پروژه اتوماسیون آریامن

این ZIP نسخه کامل سورس پروژه است و آخرین اصلاحات را دارد.

## شامل آخرین تغییرات
- متن برند بالای برنامه: `اتوماسیون آریامن`
- اصلاح CRM مشتریان و مختصر شدن ستون‌ها
- ستون عملیات CRM فقط: پرونده، ویرایش، غیرفعال
- مراحل سفارش با ظاهر نزدیک‌تر به HTML
- باز شدن جزئیات سفارش از سمت چپ
- کادر تا تحویل نهایی در پایین/راست کارت سفارش
- تنظیم مراحل و ساخت قالب جدید با تعداد مرحله انتخابی
- نمایش قالب‌های فعال در ثبت سفارش جدید
- تاریخ شمسی در ورودی‌های اصلی
- خروجی‌های Excel/PDF برنددار با لوگوی داخلی
- اصلاحات قبلی سفارش، مالی، انبار و CRM

## روش آپلود با GitHub Desktop
1. فایل ZIP را Extract کن.
2. وارد پوشه Extract شده شو.
3. همه فایل‌ها و پوشه‌های داخل آن را Copy کن.
4. برو به پوشه پروژه اصلی خودت: `otomasion3`
5. Paste کن و اگر پرسید Replace / Overwrite، تأیید کن.
6. GitHub Desktop را باز کن.
7. در Summary بنویس:
   `full latest project update`
8. Commit to main را بزن.
9. Push origin را بزن.
10. در Netlify اگر لازم بود:
    `Trigger deploy > Clear cache and deploy site`
11. سایت را با این آدرس تست کن:
    `https://otomasion3.netlify.app/?v=full-latest-2026-08-08`
