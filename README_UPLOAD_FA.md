# راهنمای آپلود نسخه کامل پروژه اتوماسیون آریامان

این فایل ZIP نسخه کامل سورس پروژه است و برای آپلود/جایگزینی در ریپوی GitHub `otomasion3` آماده شده است.

## داخل این نسخه چه چیزهایی هست؟
- React/Vite کامل پروژه
- ماژول‌های سفارش/CRM، مالی/حسابداری، انبار
- کامپوننت ارجاعات مشترک
- فایل‌های Preview HTML برای سفارش، مالی، انبار، تولید، R&D و اداری
- مایگریشن‌های Supabase تا شماره 017
- قالب اکسل انبار
- لوگوی آریامان و هماهنگی رنگ‌ها

## روش پیشنهادی آپلود با GitHub Desktop
1. فایل ZIP را Extract کن.
2. وارد پوشه Extract شده شو.
3. همه فایل‌ها و پوشه‌های داخل آن را Copy کن.
4. برو به پوشه پروژه اصلی روی کامپیوترت که به GitHub وصل است: `otomasion3`.
5. فایل‌ها را Paste کن و اگر پرسید Replace، گزینه Replace / Overwrite را بزن.
6. GitHub Desktop را باز کن.
7. باید تغییرات را ببینی.
8. پایین سمت چپ در Summary بنویس:
   `full project update - phase 1 latest`
9. Commit to main را بزن.
10. Push origin را بزن.
11. در Netlify برو به Deploys و اگر لازم بود `Trigger deploy > Clear cache and deploy site` را بزن.
12. سایت را با این آدرس تست کن:
   `https://otomasion3.netlify.app/?v=2026-08-07-full`

## اگر می‌خواهی مستقیم روی Netlify فایل آپلود کنی
این ZIP برای سورس پروژه و GitHub است، نه Drag & Drop مستقیم Netlify. برای Drag & Drop مستقیم Netlify باید پوشه `dist` جداگانه ساخته و آپلود شود.

## خیلی مهم درباره Supabase
اگر SQL جدید اجرا می‌کنی، مرحله‌به‌مرحله اجرا کن. اگر هر خطایی دیدی، ادامه نده و عکس/متن خطا را بفرست.
