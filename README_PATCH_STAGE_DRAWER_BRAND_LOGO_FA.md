# پچ اصلاح مراحل سفارش، برند، CRM و لوگوی خروجی‌ها

تاریخ آماده‌سازی: 2026-08-08

## تغییرات انجام‌شده طبق درخواست جدید

1. متن گوشه بالای برنامه دقیقاً به شکل درخواستی تغییر کرد:
   `اتوماسیون آریامن`

2. بخش `مراحل سفارش` بازطراحی شد تا از نظر رنگ، جزئیات و چیدمان نزدیک به عکس ارسالی و فایل HTML باشد:
   - نمای تمام‌عرض برای مراحل سفارش
   - فیلترهای مسیر و وضعیت در بالای صفحه
   - کارت‌های بزرگ‌تر و تمیزتر
   - برچسب‌های وضعیت مثل فوری/انبار/مالی/موعد
   - نوار پیشرفت با رنگ سرمه‌ای/مسی/سبز هماهنگ با طرح
   - Stepper مرحله‌ای با دایره‌ها و خط اتصال
   - نمایش درصد پیشرفت و مرحله فعلی

3. با کلیک روی `جزئیات و عملیات`، پنل اطلاعات سفارش به صورت Drawer از سمت چپ صفحه باز می‌شود؛ مثل رفتار فایل HTML.

4. در جدول مشتریان CRM این ستون‌ها حذف شد تا لیست مختصر و خواناتر باشد:
   - ایمیل
   - روش ارتباط
   - پیگیری بعدی

5. جدول CRM حالا کوتاه‌تر و مناسب‌تر است و فقط اطلاعات اصلی را نشان می‌دهد:
   - نام
   - نوع
   - تلفن
   - امتیاز
   - تعداد سفارش
   - فروش کل
   - عملیات

6. لوگوی خروجی‌ها دیگر به مسیر خارجی/فایل جدا وابسته نیست. لوگو داخل خروجی‌ها به صورت Base64/Data URI قرار داده شد تا در PDF/چاپ/Excel هم همراه فایل باشد.

7. خروجی‌های برنددار سفارش، CRM، مالی و انبار با برند جدید `اتوماسیون آریامن` و لوگوی داخلی کار می‌کنند.

## Build

Build با دستور زیر تست شد و موفق بود:

`npm run build`

فقط هشدار بزرگ بودن chunk وجود دارد که به خاطر React/XLSX و لوگوی داخلی در خروجی‌هاست و خطای Build نیست.

## روش نصب پچ

1. فایل ZIP را دانلود و Extract کن.
2. وارد پوشه Extract شده شو.
3. فایل‌ها و پوشه‌های داخل آن را Copy کن.
4. برو به پروژه اصلی خودت: `otomasion3`
5. Paste کن و اگر پرسید Replace / Overwrite، تأیید کن.
6. GitHub Desktop را باز کن.
7. Summary بنویس:
   `fix order flow drawer crm compact brand logo exports`
8. Commit to main را بزن.
9. Push origin را بزن.
10. در Netlify اگر لازم بود:
    `Trigger deploy > Clear cache and deploy site`
11. سایت را با آدرس زیر تست کن:
    `https://otomasion3.netlify.app/?v=stage-drawer-brand-logo-v1`

## تست سریع

- بالای برنامه باید نوشته باشد: `اتوماسیون آریامن`
- تب مراحل سفارش را باز کن؛ باید تمام‌عرض و شبیه عکس باشد.
- روی `جزئیات و عملیات` بزن؛ پنل باید از چپ باز شود.
- در CRM ستون‌های ایمیل، روش ارتباط و پیگیری بعدی نباید در جدول مشتریان دیده شود.
- از سفارش/CRM/مالی/انبار خروجی بگیر؛ لوگو باید داخل خروجی باشد.
