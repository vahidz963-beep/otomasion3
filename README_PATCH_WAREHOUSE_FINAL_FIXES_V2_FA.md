## اصلاحات خطای سند موقت

1. خطای حذف/انصراف سند موقت رفع شد:
   `warehouse_document_lines_tx_id_fkey`

علت خطا این بود که تراکنش انبار قبل از ردیف سند حذف می‌شد. در SQL جدید ترتیب حذف اصلاح شد.

2. حذف ردیف سند موقت هم اصلاح شد تا اول ارتباط `tx_id` قطع شود و بعد تراکنش حذف شود.

## اصلاحات سندها

3. ورود و خروج هر دو می‌توانند سند موقت جداگانه داشته باشند.
4. سند موقت ورود و سند موقت خروج هم‌زمان و جداگانه در بخش اسناد نمایش داده می‌شوند.
5. برای هر سند موقت این فیلدها اضافه شد:
   - نام مشتری / تحویل‌گیرنده
   - شرح کلی سند
6. فرم اطلاعات سند تمیزتر شد و ذخیره اطلاعات سند اضافه شد.
7. دکمه‌های ویرایش و حذف ردیف سند موقت زیباتر و رنگ‌بندی شدند.

## اصلاحات موجودی

8. کاردکس دیگر داخل صفحه موجودی باز نمی‌شود.
9. با زدن «مشاهده کاردکس» در منوی سه‌نقطه هر کالا، کاربر به تب اصلی «کاردکس» منتقل می‌شود و کاردکس همان کالا نمایش داده می‌شود.
10. تب «کاردکس» دوباره به منوی اصلی انبار برگشت.
11. در کاردکس امکان سرچ کالا و انتخاب کالا وجود دارد.
12. جدول موجودی فشرده‌تر شد تا اسکرول افقی کمتر/حذف شود و حداقل حدود ۱۰ ردیف دیده شود.
13. دکمه‌های عملیات موجودی مرتب‌تر شدند: +، -، سه‌نقطه.

## ثبت/ویرایش کالا

## SQL لازم

این دو فایل باید به ترتیب در Supabase SQL Editor اجرا شوند:

1. اگر قبلاً اجرا نکردی:
`supabase/migrations/019_warehouse_in_out_draft_documents.sql`

2. حتماً برای رفع خطای حذف سند موقت اجرا شود:
`supabase/migrations/020_warehouse_cancel_fk_meta_and_summary.sql`

اگر SQL خطا داد، ادامه نده و عکس/متن خطا را بفرست.

## Build

Build با `npm run build` موفق بود.

## نصب پچ

1. ZIP را Extract کن.
2. فایل‌ها را داخل پروژه `otomasion3` کپی کن.
3. Replace / Overwrite را تأیید کن.
4. GitHub Desktop → Commit to main
5. Push origin
6. SQLهای 019 و 020 را در Supabase اجرا کن.
7. Netlify → Clear cache and deploy site
8. تست:
`https://otomasion3.netlify.app/?v=warehouse-final-v2`
