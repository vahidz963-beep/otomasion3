# نسخه ۱۲۹ — ویرایش و حذف امن اسناد پرداخت حقوق

## تغییرات اصلی

- افزودن دکمه‌های «ویرایش» و «حذف» کنار هر سند پرداخت در پرونده حقوق شخص.
- امکان ویرایش مبلغ، تاریخ، حساب بانکی/کارت، صندوق و یادداشت پرداخت.
- حذف به‌صورت ابطال امن انجام می‌شود و هیچ رکورد مالی به‌صورت فیزیکی حذف نمی‌شود.
- هنگام ویرایش، سند حسابداری قبلی باطل و سند حسابداری هماهنگ جدید ثبت می‌شود.
- هنگام ابطال، اثر سند از گردش بانک/صندوق و سند حسابداری برگشت داده می‌شود.
- مبلغ پرداخت‌شده، مانده فیش، وضعیت فیش و جمع‌های ماه بلافاصله دوباره محاسبه می‌شوند.
- در سوابق فیش‌های هر شخص، برای فیش دارای مانده دکمه «ثبت پرداخت» اضافه شده است.
- ویرایش سند پرداخت حقوق از بخش «صندوق و گردش حساب» نیز فرم اصلی پرداخت حقوق را باز می‌کند.
- ابطال سند پرداخت حقوق از بخش گردش حساب نیز از مسیر اتمیک و امن حقوق انجام می‌شود.
- پرداخت‌شده فیش دیگر دستی نیست و فقط از اسناد پرداخت فعال محاسبه می‌شود.

## Migration الزامی

فایل زیر را یک‌بار در Supabase SQL Editor اجرا کنید:

`supabase/migrations/121_payroll_payment_edit_void_sync.sql`

این Migration:

- وضعیت active/void و اطلاعات حسابرسی ابطال را به پرداخت‌های حقوق اضافه می‌کند.
- RPCهای اتمیک ویرایش و ابطال را می‌سازد.
- محاسبه فیش را فقط بر اساس پرداخت‌های فعال اصلاح می‌کند.
- رکوردهای قدیمی مرتبط با اسناد دریافت/پرداخت باطل‌شده را همگام‌سازی می‌کند.
- حذف مستقیم فیزیکی پرداخت حقوق را برای کاربران احراز هویت‌شده می‌بندد.

> Migration ۱۱۹ قبلاً اجرا شده و برای این نسخه نباید دوباره اجرا شود. Migration جدید این قابلیت فقط شماره ۱۲۱ است.

## Deploy با GitHub Desktop

1. فایل‌های این نسخه را روی پروژه کپی کنید.
2. فایل Migration ۱۲۱ را یک‌بار در Supabase اجرا کنید.
3. در GitHub Desktop گزینه `Commit to main` را بزنید.
4. سپس `Push origin` را اجرا کنید.

## کنترل انجام‌شده

- Build تولید با موفقیت انجام شد.
- Syntax کامل Migration ۱۲۱ با parser سازگار PostgreSQL بررسی شد.
- ZIP نسخه با `unzip -t` کنترل می‌شود.
