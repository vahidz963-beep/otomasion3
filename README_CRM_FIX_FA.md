# اصلاح CRM و پیگیری‌ها — 2026-08-07

این نسخه مشکل اصلی بخش پیگیری CRM را اصلاح می‌کند.

## تغییرات مهم

1. ثبت «پیگیری CRM» دیگر فقط یک Interaction نمایشی نیست؛ حالا رکورد واقعی در جدول `crm_followups` ثبت می‌شود.
2. هنگام ثبت پیگیری:
   - در `crm_followups` ثبت می‌شود.
   - در `crm_interactions` هم سابقه تعامل ثبت می‌شود.
   - `next_follow_up_at` مشتری به‌روزرسانی می‌شود.
   - اگر سفارش مرتبط انتخاب شده باشد، در تاریخچه سفارش هم Event از نوع CRM ثبت می‌شود.
3. دکمه «انجام شد» برای بستن پیگیری اضافه شد.
4. ظاهر صفحه CRM به فایل HTML سفارش‌ها نزدیک‌تر شد:
   - فیلتر مشتری/سرنخ
   - فیلتر روش ارتباط
   - کارت پیگیری‌های امروز
   - قیف فروش ساده
   - آخرین تعاملات
   - پرونده مشتری
   - عملیات پرونده، پیگیری، سفارش و غیرفعال‌سازی مشتری
5. تاریخ‌ها در CRM و ارجاعات به‌صورت شمسی نمایش داده می‌شوند.
6. عنوان سامانه به «اتوماسیون آریامان» اصلاح شد.

## SQL لازم در Supabase

بعد از آپلود سورس و Deploy، این فایل SQL را در Supabase اجرا کن:

`supabase/migrations/018_crm_followup_real_save_and_ui_support.sql`

مسیر اجرا:

Supabase Dashboard → SQL Editor → New query → محتوای فایل 018 را Paste کن → Run

اگر هر خطایی داد، ادامه نده و عکس/متن خطا را بفرست.

## تست بعد از Deploy

1. وارد سایت شو.
2. برو به سفارش‌ها و CRM فروش.
3. تب `CRM مشتریان` را باز کن.
4. روی `＋ پیگیری CRM` بزن.
5. مشتری، تاریخ، ساعت و عنوان را وارد کن.
6. ثبت کن.
7. باید در کارت `پیگیری‌های امروز و باز` نمایش داده شود.
8. روی `انجام شد` بزن.
9. باید از لیست پیگیری‌های باز حذف شود و در آخرین تعاملات ثبت شود.
