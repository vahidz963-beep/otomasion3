# پچ V2 اصلاح CRM، مراحل سفارش، قالب مراحل و خروجی Excel

تاریخ آماده‌سازی: 2026-08-08

## موارد اجراشده به ترتیب درخواست

### 1. CRM مشتریان — ستون عملیات و عرض ستون‌ها
در جدول مشتریان CRM، ستون عملیات فقط این سه گزینه را دارد:

- پرونده
- ویرایش
- غیرفعال

گزینه‌های اضافه مثل پیگیری و سفارش از ستون عملیات حذف شد. ستون‌های جدول هم دوباره تنظیم شد تا برای نام و تلفن فضای کافی باشد و ستون‌ها با هم تداخل نداشته باشند.

### 2. مراحل سفارش — کادر تا تحویل نهایی
کادر `تا تحویل نهایی` به گوشه سمت راست پایین هر کارت سفارش منتقل شد.

### 3. جزئیات سفارش از سمت چپ
در بخش مراحل سفارش، با زدن روی دکمه `جزئیات و عملیات`، صفحه جزئیات سفارش به صورت پنل کشویی از سمت چپ باز می‌شود.

### 4. تنظیم مراحل — افزودن قالب دلخواه فروشنده
در بخش `تنظیم مراحل` قابلیت ساخت قالب جدید اضافه شد:

- نام قالب جدید
- مسیر قالب: همه مسیرها / بازرگانی / R&D / تولید مستقیم
- تعداد مراحل از ۴ تا ۱۲ مرحله
- دکمه ساخت قالب

قالب جدید بعد از ساخت فعال است و در فرم `ثبت سفارش جدید` در قسمت `قالب مراحل` قابل مشاهده و انتخاب می‌شود.

### 5. خروجی Excel تمیزتر و قابل نمایش‌تر
ساختار خروجی Excel اصلاح شد:

- جدول با border و سلول‌بندی واضح
- سربرگ رسمی
- لوگوی داخلی به صورت Base64/Data URI
- متن برند `اتوماسیون آریامن`
- حذف CSS پیچیده از خروجی Excel و تبدیل به HTML سازگارتر با Excel

## Build
Build با دستور زیر موفق بود:

`npm run build`

هشدار حجم chunk وجود دارد، چون لوگو داخل خروجی‌ها Embed شده است؛ خطای Build نیست.

## روش نصب پچ

1. فایل ZIP را دانلود کن.
2. Extract کن.
3. وارد پوشه Extract شده شو.
4. همه فایل‌ها و پوشه‌های داخل آن را Copy کن.
5. داخل پروژه اصلی `otomasion3` Paste کن.
6. اگر پرسید Replace / Overwrite، تأیید کن.
7. GitHub Desktop را باز کن.
8. Summary بنویس:
   `crm actions order due box templates excel output v2`
9. Commit to main بزن.
10. Push origin بزن.
11. در Netlify اگر لازم بود Clear cache and deploy site بزن.
12. تست با:
   `https://otomasion3.netlify.app/?v=crm-stage-template-excel-v2`

## نکته
این پچ SQL جدید ندارد. ساخت قالب جدید از طریق جدول‌های موجود Supabase انجام می‌شود. اگر موقع ساخت قالب خطای Supabase دیدی، ادامه نده و عکس/متن خطا را بفرست.
