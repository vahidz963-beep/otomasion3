# مرحله ادامه: نقش‌ها، دسترسی دیتابیس و بهینه‌سازی سرعت

تاریخ: 2026-08-14

## انجام‌شده

### 1. بهینه‌سازی سرعت و حجم برنامه
- ماژول‌ها در `src/App.jsx` از import مستقیم به Lazy Loading تغییر کردند.
- هر ماژول به صورت جداگانه بارگذاری می‌شود.
- نتیجه Build بهتر شد و فایل‌های ماژول‌ها جدا شدند.
- هشدار بزرگ بودن chunk اصلی عملاً کاهش پیدا کرد.

### 2. بهبود منوی نقش‌ها
- منوی بالا بر اساس تمام نقش‌های کاربر (`role` + `additional_roles`) ساخته می‌شود.
- اگر کاربر چند نقش داشته باشد، فقط ماژول‌های همان نقش‌ها را می‌بیند.
- مدیر کل همه ماژول‌ها را می‌بیند.

### 3. داشبورد اختصاصی نقش‌ها
- داشبورد بر اساس نقش کاربر فیلتر می‌شود.
- مدیر کل داشبورد کامل + Health Check می‌بیند.
- فروش، مالی، انبار، تولید، R&D و اداری هر کدام اطلاعات مربوط به خودشان را می‌بینند.

### 4. RLS و Role Helper در دیتابیس
Migration جدید اضافه شد:

`supabase/migrations/033_rbac_rls_hardening.sql`

این فایل:
- `current_role_names()` را اضافه می‌کند.
- `has_role()` را با چندنقشی هماهنگ می‌کند.
- `is_admin()` را با چندنقشی هماهنگ می‌کند.
- `fn_user_can_access_order()` را برای sales_manager و نقش‌های عملیاتی اصلاح می‌کند.
- policyهای سفارش/CRM/ارجاعات را با چندنقشی هماهنگ‌تر می‌کند.
- `sales_manager` را به بخش فروش/سفارش اضافه می‌کند.

## SQL لازم
