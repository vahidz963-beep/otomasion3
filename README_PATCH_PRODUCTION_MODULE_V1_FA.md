# پچ ماژول تولید V1 — فرانت‌اند + بک‌اند

تاریخ آماده‌سازی: 2026-08-09

این پچ ماژول تولید واقعی را جایگزین Placeholder قبلی می‌کند و شامل کدهای React، API، Hook و Migration بک‌اند Supabase است. فایل HTML جدا ندارد.

## قابلیت‌های اضافه‌شده

### 1. اتصال سفارش‌ها به تولید
- سفارش‌هایی که در ماژول سفارش با مسیر `production` ثبت شده‌اند و هنوز وارد تولید نشده‌اند در بخش «تأیید سفارش» دیده می‌شوند.
- با زدن «تأیید و ورود به تولید»، سفارش به تولید تبدیل می‌شود.
- بعد از تأیید، در جدول `production_orders` ثبت می‌شود.
- در سفارش اصلی هم `production_order_id` ثبت می‌شود.
- در تاریخچه سفارش event تولید اضافه می‌شود.

### 2. تیترهای اصلی ماژول تولید
در بالای صفحه تولید این گزینه‌ها اضافه شد:
- تأیید سفارش
- مراحل تولید
- به‌روزرسانی

### 3. تب‌های اصلی تولید
این بخش‌ها ساخته شد:
- نمای کلی
- مراحل تولید
- لیست سفارش‌ها / تأیید سفارش‌های رسیده
- برنامه‌ریزی تولید
- فرمول تولید کالا
- کنترل کیفیت
- اسناد تولید
- ارجاع
- تنظیم مراحل

### 4. قالب‌های مراحل تولید
قالب‌های اولیه ساخته شدند:
- تولید پاور سوئیچینگ ۱۰ مرحله‌ای
- تولید برد ۸ مرحله‌ای
- تولید محصول کامل ۱۲ مرحله‌ای

در بخش تنظیم مراحل امکان ساخت قالب جدید با ۴ تا ۱۵ مرحله وجود دارد.

قابلیت‌های تنظیم مراحل:
- ساخت قالب جدید
- تعیین نوع تولید
- تعیین تعداد مراحل ۴ تا ۱۵
- فعال/غیرفعال کردن قالب
- ویرایش نام مرحله
- تغییر ترتیب مرحله
- تعیین مسئول مرحله
- تعیین اینکه مرحله نیاز به خروج مواد دارد یا QC دارد
- اضافه کردن مرحله جدید

### 5. مراحل تولید مثل سفارش‌ها
در بخش مراحل تولید:
- کارت‌های تولید با نوار پیشرفت و Stepper مرحله‌ای نمایش داده می‌شود.
- با زدن جزئیات، پنل جزئیات از سمت چپ باز می‌شود.
- امکان تغییر مرحله از داخل پنل وجود دارد.

### 6. برنامه‌ریزی تولید
برای هر سفارش تولید می‌توان ثبت کرد:
- تاریخ شروع شمسی
- تاریخ پایان شمسی
- تعداد روز کاری
- تعداد نفرات موردنیاز
- ساعت هر نفر
- نفرساعت کل پروژه
- توضیح/فیدبک تحویل

بعد از ذخیره برنامه، به تاریخچه سفارش اصلی event تولید اضافه می‌شود.

### 7. فرمول تولید کالا / BOM
در بخش فرمول تولید:
- انتخاب کالا از انبار یا محصول جدید
- تعریف ردیف‌های متریال، نیروی انسانی، سربار و خدمات
- انتخاب متریال از انبار و دریافت قیمت مرجع
- محاسبه هزینه کل متریال، نیرو/خدمات، سربار و جمع نهایی
- ارجاع هزینه تولید به مالی

### 8. کنترل کیفیت
امکان ثبت QC برای هر سفارش تولید:
- نتیجه قبول / رد / نیاز به اصلاح
- تعداد بررسی‌شده
- تعداد قبول
- تعداد رد
- دلیل رد یا اصلاح

### 9. اسناد تولید
امکان ثبت و مدیریت سند تولید:
- دستور تولید
- مصرف مواد
- گزارش QC
- خروجی تولید
- هزینه
- سایر

### 10. ارجاعات تولید
بخش ارجاعات تولید با `ReferralPanel` مشترک اضافه شد.

## SQL لازم

بعد از کپی فایل‌ها و Push، این SQL را در Supabase اجرا کن:

`supabase/migrations/021_production_module_backend_workflow.sql`

اگر SQL خطا داد، ادامه نده و عکس/متن خطا را بفرست.

## روش نصب پچ

1. ZIP را Extract کن.
2. فایل‌ها را داخل پروژه `otomasion3` کپی کن.
3. Replace / Overwrite را تأیید کن.
4. GitHub Desktop را باز کن.
5. Summary بنویس:
   `add production module v1`
6. Commit to main بزن.
7. Push origin بزن.
8. SQL شماره 021 را در Supabase اجرا کن.
9. در Netlify Deploy بگیر.
10. تست:
   `https://automationarya.netlify.app/?v=production-module-v1`

## تست سریع

1. وارد سایت شو.
2. منوی تولید را باز کن.
3. در تب تأیید سفارش، سفارش‌های production باید دیده شوند.
4. یک سفارش را تأیید کن.
5. به تب مراحل تولید برو؛ کارت تولید باید ساخته شده باشد.
6. برنامه‌ریزی تولید را ثبت کن.
7. یک فرمول تولید بساز و هزینه را به مالی ارجاع بده.
8. QC و سند تولید ثبت کن.
