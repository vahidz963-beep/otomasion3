# پچ نهایی اصلاح CRM، هدر سفارش و قالب مراحل

تاریخ آماده‌سازی: 2026-08-08

## اصلاحات انجام‌شده

### 1. CRM مشتریان
- لیست مشتریان عریض‌تر شد.
- لیست پیگیری‌های امروز کوچک‌تر شد.
- ستون عملیات به‌صورت عمودی باقی ماند تا نوشته‌ها تداخل نداشته باشند.
- فضای ستون نام و تلفن بیشتر شد.

### 2. نوار آبی بالای سفارش‌ها
فقط چهار دکمه اصلی باقی ماند:

1. سفارش جدید
2. پیگیری CRM
3. مشتری/سرنخ
4. به‌روزرسانی

عددهای ۱،۲،۳،۴ از متن دکمه‌ها حذف شد.
دکمه‌های `خروجی Excel` و `چاپ/PDF` از این بخش حذف شدند.

### 3. قالب مراحل در ثبت سفارش جدید
- در فرم ثبت سفارش جدید، همه قالب‌های فعال نمایش داده می‌شوند.
- قالب‌های غیرفعال نمایش داده نمی‌شوند.
- فیلتر مسیر حذف شد تا همه قالب‌های فعال قابل انتخاب باشند.
- کنار نام هر قالب، مسیر و تعداد مراحل هم نشان داده می‌شود.

## Build
Build با دستور `npm run build` موفق بود.

## نصب
1. ZIP را Extract کن.
2. فایل‌ها را داخل پروژه `otomasion3` کپی کن.
3. Replace / Overwrite را تأیید کن.
4. Commit و Push کن.
5. Netlify را Deploy کن.

لینک تست پیشنهادی:
`https://otomasion3.netlify.app/?v=final-order-crm-fixes`
