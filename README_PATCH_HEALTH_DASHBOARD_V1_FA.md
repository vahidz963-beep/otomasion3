# پچ Health Check و داشبورد مدیریتی V1

تاریخ آماده‌سازی: 2026-08-14

## بخش ۱ — Health Check پایدارسازی دیتابیس

یک تابع جدید اضافه شد:

`fn_system_health_report()`

فایل SQL:

`supabase/migrations/032_system_health_report.sql`

این تابع موارد زیر را بررسی می‌کند:

- وجود جدول‌های اصلی
- وجود Viewهای اصلی
- وجود RPCهای اصلی
- فعال بودن RLS روی جدول‌ها
- وجود grantهای authenticated
- وجود bucket فایل‌های اشتراکی در Storage
- وضعیت ماژول‌ها: سفارش، CRM، انبار، مالی، تولید، R&D، فایل‌های اشتراکی

خروجی تابع JSON است و در داشبورد مدیریتی نمایش داده می‌شود.

## بخش ۲ — داشبورد مدیریتی اصلی

داشبورد به صورت مدیریتی بازطراحی شد:

- کارت‌های KPI اجرایی
- سفارش‌های باز
- دریافتنی‌ها
- پرداختنی‌ها
- سررسید گذشته
- کم‌موجودی
- تولید فعال
- R&D فعال
- ارجاعات باز
- نمودار روند سفارش‌ها
- نمودار روند واریز/برداشت
- جدول ارجاعات فوری
- جدول کم‌موجودی
- جدول تولیدهای در جریان
- جدول R&D در جریان
- جدول چک‌های نزدیک
- جدول آخرین گردش‌ها

## نکته دسترسی

داشبورد مدیریتی کامل برای مدیر کل نمایش داده می‌شود. نقش‌های دیگر داشبورد کاری محدودتر می‌بینند.

## SQL لازم

در Supabase اجرا کن:

`supabase/migrations/032_system_health_report.sql`

اگر SQL خطا داد، ادامه نده و عکس/متن خطا را بفرست.

## نصب پچ

1. ZIP را Extract کن.
2. فایل‌ها را داخل پروژه اصلی کپی کن.
3. Replace / Overwrite را تأیید کن.
4. Commit و Push کن.
5. SQL شماره 032 را اجرا کن.
6. Netlify را Clear cache deploy کن.

Build با `npm run build` موفق بود.
